## Python How-To Guides

Aspose.3D FOSS for Python is a zero-dependency, MIT-licensed library for reading and writing common 3D file formats. Install it with:

```bash
pip install aspose-3d-foss
```

The articles below walk through the most common tasks step by step, with working code at every stage.

---

## Available Articles

### Loading 3D Models

[How to Load 3D Models in Python](how-to-load-3d-models-in-python/)

Open OBJ, STL, glTF, COLLADA, and 3MF files into a `Scene` object, traverse the node hierarchy, and read mesh geometry including vertices, polygons, normals, and UV coordinates.

### Converting Between Formats

[How to Convert 3D Models in Python](how-to-convert-3d-models-in-python/)

Load a source file in one format and save it to another — for example OBJ to STL, OBJ to glTF 2.0, or STL to 3MF — using format-specific load and save options to control coordinate systems, scaling, and material handling.
