Aspose.3D FOSS for TypeScript (`@aspose/3d`) is an MIT-licensed Node.js library for reading, writing, and converting 3D scene files. It supports OBJ, glTF 2.0, GLB, STL, 3MF, FBX, and COLLADA formats with full TypeScript type definitions included.

## Platform

- **Runtime**: Node.js 16, 18, 20, 22+
- **Language**: TypeScript 5.0+ / JavaScript (CommonJS)
- **License**: MIT
- **Package**: `@aspose/3d`

## How-To Articles

### [How to Load 3D Models in TypeScript](how-to-load-3d-models-in-typescript/)

Learn how to install `@aspose/3d`, open OBJ and other 3D format files, iterate over the scene graph, and access mesh vertex data from a Node.js application.

### [How to Export 3D Scenes to glTF/GLB in TypeScript](how-to-export-gltf-in-typescript/)

Learn how to configure `GltfSaveOptions`, switch between JSON glTF and binary GLB output, and save a loaded or programmatically built scene using `scene.save()`.
