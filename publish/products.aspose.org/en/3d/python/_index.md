# Overview
overview:
  enable: true
  content: |
    Aspose.3D FOSS for Python is a MIT-licensed, pure-Python library for working with 3D file formats. Install it with a single pip command and immediately start reading, constructing, and writing 3D scenes without installing any native runtime, external SDK, or third-party renderer.

    The library exposes a clean scene-graph API built around Scene, Node, Mesh, Camera, Light, and Transform — the same conceptual model used by professional 3D tools. Format support includes OBJ (with .mtl material loading), STL (binary and ASCII, roundtrip verified), glTF 2.0 / GLB, COLLADA (DAE), 3MF, and an in-progress FBX tokenizer. Per-format load and save options let you control coordinate flipping, scale, normal normalization, and material loading without writing any format-specific parsing code.

    Because Aspose.3D FOSS has zero external dependencies and supports Python 3.7 through 3.12, it runs identically on Windows, macOS, and Linux CI runners, Docker containers, and serverless environments. There is no native extension to compile and no system package to install.
