## Common Issues

If `Presentation` throws UnsupportedFormatException when loading `a` file, the file is either corrupted or in `a` format not supported by Aspose.Slides FOSS for Java. The library only supports `.pptx` files with full round-trip fidelity; older `.ppt` files are not supported. Check the file extension and ensure it is `a` valid Office Open XML presentation.

If `Slide.getShapes()` returns an empty collection despite expecting shapes, verify that the slide `contains` shapes in the source `.pptx` file. Aspose.Slides FOSS for Java preserves all shapes during load/save, but some third-party tools may generate non-standard `.pptx` structures that the library cannot parse correctly. Try opening the file in Microsoft PowerPoint to confirm shape presence.

If text formatting changes unexpectedly after saving, ensure you are using only the supported text formatting APIs: `TextFrame`, `Paragraph`, and `Portion` with `BasePortionFormat`. Aspose.Slides FOSS for Java does not implement advanced text effects or complex layout features — the following areas are not implemented: 3D text, text animation, and advanced typography features like ligatures or kerning overrides.

```java
import com.aspose.slides.*;

Presentation pres = new Presentation("input.pptx");
ISlide slide = pres.getSlides().get(0);
slide.getShapes().addAutoShape(ShapeType.Rectangle, 50, 50, 200, 100);
pres.save("output.pptx", SaveFormat.Pptx);
```

## Error Messages

If `Presentation` throws FileFormatException, the file is corrupted or in an unsupported format. Aspose.Slides FOSS for Java only supports `.pptx` files; `.ppt` or other legacy formats will trigger this error. Check the file extension and ensure it is `a` valid Office Open XML presentation.

| Error | Cause | Fix |
|-------|-------|-----|
| `FileFormatException: The file is not a valid Office Open XML file` | File is not `a` `.pptx` (e.`g`., `.ppt`, `.pdf`, or binary) | Replace the input file with `a` valid `.pptx` generated by PowerPoint or Aspose.Slides |
| NullPointerException at `Slide.getShapes()` | `Slide` was removed or never added to `Presentation.getSlides()` | Verify slide index is within bounds using `getSlides().getCount()` before accessing |
| UnsupportedOperationException when calling `CommentCollection.add()` | `Comment` authoring is not implemented in FOSS edition | Avoid comment creation; use `Comment` only for reading existing comments |
| `[identifier omitted]: Unexpected end of stream` | File truncated or partially written due to missing save() call | Always call `presentation.save(path, SaveFormat.Pptx)` after modifications |
| `ClassCastException: Aspose.Slides FOSS for Java.internal.* cannot be cast to Aspose.Slides FOSS for Java.*` | Mixing FOSS and commercial JARs in classpath | Remove all non-`com.aspose.slides.*` JARs; use only the official FOSS distribution |
| NoSuchElementException at `Shape.getTextFrame()` | `Shape` is not `a` text-capable type (e.`g`., `PictureFrame`) | Check `shape.getShapeType()` before accessing getTextFrame() |
| `IllegalArgumentException: Invalid slide index` | Index < 0 or ≥ `getSlides().getCount()` | Validate index: `if (index >= 0 && index < slides.getCount())` before `get(index)` |

## Getting Help

If `Presentation` fails to load `a` `.pptx` file, verify the file is not corrupted and uses `a` supported format. Check the file extension and ensure it matches the actual content structure.

- Report bugs or request features via GitHub Issues: https://github.com/aspose-slides-cloud/aspose-slides-cloud-java/issues

- Search or ask questions on Stack Overflow using tags `slides-java` or `aspose-slides`

Note: Aspose.Slides FOSS for Java has known limitations — the following areas are not implemented: advanced animation timelines, complex 3D scene rendering, and macro execution.
