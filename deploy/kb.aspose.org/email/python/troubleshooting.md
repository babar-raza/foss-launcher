## Common Issues

If `CFBDocument.from_file()` or `MapiMessage.from_file()` raises `CFBError`, the input file contains malformed or unsupported Compound File Binary (CFB) content. This error originates from the low-level CFB reader and indicates structural corruption or an incompatible file format.

Check that the file is a valid Outlook MSG file (a CFB container) and not a plain text, HTML, or EML file. MSG files must begin with the CFB signature `0xD0CF11E0A1B11AE1`. Use a hex editor or `CFBReader` to verify the header before loading with `MapiMessage.from_file()`.

If the file is truncated or partially downloaded, re-download or regenerate it. Corrupted files often fail at the first sector allocation table read; `CFBReader.from_file()` will raise `CFBError` with a clear message about invalid sector chains or missing directory entries.

```python
import aspose.email
from aspose.email import CFBReader, CFBError

try:
    reader = CFBReader.from_file("message.msg")
    doc = reader.to_document()  # Hypothetical helper; actual use via MapiMessage.from_file()
except CFBError as e:
    print(f"CFBError: {e}")
```

Replace any non-MSG file with a valid `.msg` file generated by Outlook or another compatible client. Do not rename `.eml`, `.oft`, or `.ost` files to `.msg`—they use different formats and will trigger `CFBError`.

## Error Messages

If `CFBDocument.from_file()` or `MapiMessage.from_file()` raises `CFBError`, the file contains malformed or unsupported Compound File Binary (CFB) content. This typically occurs when the input file is corrupted, truncated, or not a valid MSG/CFB file.

| Error | Cause | Fix |
|-------|-------|-----|
| `CFBError: Invalid CFB signature` | The file does not start with the expected CFB magic bytes (D0CF11E0A1B11AE1). | Verify the file is a valid Outlook MSG file. Re-`save` the file in Outlook or use a known-good MSG file for testing. |
| `CFBError: Sector chain overflow` | The FAT or mini-FAT sector chain references invalid or out-of-range sectors. | Check file integrity; download or regenerate the file. Avoid editing MSG files with non-MAPI tools. |
| `CFBError: Unsupported major version` | The file uses a CFB version not supported by Aspose.Email FOSS (only version 3 is supported). | Convert the file to MSG format using a compatible email client (e.g., Outlook 2016+). |
| `CFBError: Stream not found` | A required stream (e.g., `__properties_version1.0`) is missing or misnamed in the CFB directory. | Repair the MSG file using Microsoft [identifier omitted] ( Inbox Repair Tool ) or recreate it from backup. |

```python
import aspose.email
from aspose.email import CFBDocument, CFBError

try:
    doc = CFBDocument.from_file("message.msg")
except CFBError as e:
    print(f"CFBError: {e}")
    # Fix: Replace with a valid MSG file or repair the current one
```

## Getting Help

If `CFBReader.from_file()` or `CFBDocument.from_file()` raises `CFBError`, the file contains malformed or unsupported Compound File Binary (CFB) content. Verify the file is a valid MSG or OST file and not corrupted.

```python
import aspose.email
from aspose.email import CFBReader, CFBError

try:
    reader = CFBReader.from_file("message.msg")
    # Proceed with reading
except CFBError as e:
    print(f"CFBError: {e}")
```

- Check that the input file is a valid Outlook MSG file (not HTML, TXT, or corrupted).
- Try opening the file in Microsoft Outlook to confirm it loads correctly.
- If the file is from an external source, request a fresh copy to rule out transmission corruption.
