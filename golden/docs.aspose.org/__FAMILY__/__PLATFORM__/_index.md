**Transform your .NET applications with Aspose.Slides Plugins**

Welcome to the official documentation for **Aspose.Slides Plugins for .NET** - a powerful, lightweight extension system designed to enhance presentation processing capabilities in any .NET application.

With Aspose.Slides Plugins, developers can **convert**, **merge** and **extract** PowerPoint presentations with high fidelity without requiring Microsoft Office or other external dependencies. These plugins are optimized for automated workflows, batch operations, and server-side processing.

---

## Key Plugin Capabilities

* **Presentation Conversion**
  Convert PowerPoint presentations (PPT, PPTX) to:
    - PDF (digital print-ready)
    - TIFF (multi-page images)
    - PNG / JPEG (high-resolution slide images)
    - SVG (scalable vector output)
    - HTML (browser-ready interactive slides)

* **Presentation Merging**
  Combine multiple presentations into a single file while preserving animations, layout, and formatting.

* **Text Extraction**
  Extract all textual content from presentation slides for indexing, search, content analysis, AI preprocessing, and compliance workflows.

---

## Where These Plugins Are Used

* **Enterprise Automation**
  Generate reports and slide decks dynamically from business data sources.

* **Document Processing Systems**
  Build automated PowerPoint pipelines using microservices or SaaS backends.

* **Compliance & AI Systems**
  Extract text for search indexing, security scanning, or AI enrichment tasks.

* **Web & Cloud Applications**
  Convert slides to web-friendly formats such as HTML, PNG, or SVG for embedding and viewing on-line.

---

## Supported Operations

Convert presentations to high-fidelity output formats
Merge multiple PPT/PPTX files
Extract text from slides programmatically
Load presentations from streams or file paths
Save results to disk, cloud storage, or memory streams

All plugins work **server-side** with no UI and **no dependency on Microsoft Office**.
