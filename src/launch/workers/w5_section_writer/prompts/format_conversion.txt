## FORMATTING RULES

Avoid these formatting defects that cause pipeline validation failures:

- **FQ-1 Naked code**: All code — including single commands — must be in a fenced code block with a language tag (e.g., ```python or ```bash). Never write code lines as plain text outside fences.
- **FQ-3 Truncated bullets**: Every bullet point must be a complete sentence ending with a period. Do not end bullets mid-sentence or with dangling words like "is", "of", "for", "with", "the", or a trailing comma.
