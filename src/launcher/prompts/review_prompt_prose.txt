PROSE QUALITY CHECKLIST — evaluate these 5 dimensions:

1. OPENING QUALITY: Does each section lead with the reader's goal or task? Weak: "{display_name} is a library that..." Strong: "Load 3D models from disk with automatic format detection."

2. NARRATIVE FLOW: Do paragraphs build on each other, or are they interchangeable list items that could be reordered without losing meaning?

3. SENTENCE VARIETY: Are sentence lengths and openings varied? Flag 3+ consecutive sentences starting with the same subject pattern ("You can", "The library", "It supports").

4. CODE INTEGRATION: Is code explained before (what it does) and after (expected result)? Flag code blocks that appear with no surrounding prose context.

5. SPECIFICITY: Does prose name concrete classes, methods, formats, and outputs? Flag paragraphs that use only generic verbs (supports, provides, allows, enables) without concrete identifiers.

SEVERITY RULES:
- Maximum severity is MEDIUM — prose quality findings must never be HIGH or CRITICAL
- Use MEDIUM for patterns that meaningfully reduce readability or usefulness
- Use LOW for minor style preferences

ROLE-AWARE JUDGMENT:
- Reference pages: terse prose is correct — do not flag conciseness
- Blog/how-to pages: prose quality matters most — flag generic or mechanical writing
- FAQ pages: direct answers are correct — do not flag brevity
- Landing pages: concise positioning is correct — flag only generic claims
