## Overview

The `run_config.yaml` file defines all parameters for a documentation generation run. It specifies:

- **Product identity**: slug, name, family, target platform
- **Source repos**: GitHub repo URL + refs (pinned SHAs for determinism)
- **Site layout**: Content structure, subdomain roots, localization
- **Required sections**: products, docs, reference, kb, blog
- **LLM configuration**: API endpoint, model, decoding parameters
- **MCP configuration**: Server settings for Claude Desktop integration
- **Telemetry**: Endpoint URL, project, auth token
- **Commit service**: GitHub commit service endpoint and templates
- **Budgets**: Runtime limits and circuit breakers

---

## Required Fields

| Field | Type | Description |
|-------|------|-------------|
| `schema_version` | string | Schema version (e.g., "1.0.0") |
| `product_slug` | string | Unique product identifier (e.g., "cells") |
| `product_name` | string | Human-readable product name (e.g., "Aspose.Cells for Python") |
| `family` | string | Product family (e.g., "3d", "cells", "words") |
| `github_repo_url` | string | Product repository URL |
| `github_ref` | string | Commit SHA (40-char hex) for product repo |
| `required_sections` | array | Required content sections |
| `site_layout` | object | Site layout configuration |
| `allowed_paths` | array | Write fence - allowed content paths |
| `llm` | object | LLM provider configuration |
| `mcp` | object | MCP server configuration |
| `telemetry` | object | Telemetry endpoint configuration |
| `commit_service` | object | GitHub commit service configuration |
| `templates_version` | string | Template version lock |
| `ruleset_version` | string | Ruleset version lock |
| `allow_inference` | boolean | Allow LLM inference |
| `max_fix_attempts` | integer | Maximum fix loop attempts |
| `budgets` | object | Runtime budget limits |
| `target_platform` | string | Target platform (python, typescript, etc.) |
| `skip_sections` | array | Sections to skip during page planning |
| `allow_manual_edits` | boolean | Emergency-only manual content edits |
| `seo_enabled` | boolean | Enable W10 SEO Optimizer |
| `taskcard_id` | string | Taskcard ID authorizing file modifications |
| `ingestion` | object | Configurable ingestion settings |

## Configuration Reference

### `target_platform`

| Value | Description |
|-------|-------------|
| `python` | Python SDK |
| `typescript` | TypeScript SDK |
| `javascript` | JavaScript SDK |
| `java` | Java SDK |
| `dotnet` | .NET SDK |
| `cpp` | C++ SDK |
| `go` | Go SDK |
| `ruby` | Ruby SDK |
| `php` | PHP SDK |
| `kotlin` | Kotlin SDK |
| `swift` | Swift SDK |
| `rust` | Rust SDK |

### `required_sections`

| Value | Description |
|-------|-------------|
| `products` | Product landing pages |
| `docs` | Documentation and tutorials |
| `reference` | API reference |
| `kb` | Knowledge base (FAQ, troubleshooting) |
| `blog` | Blog posts and announcements |

### `site_layout`

```yaml
site_layout:
  content_root: "content"
  subdomain_roots:
    products: "content/products.aspose.org"
    docs: "content/docs.aspose.org"
    kb: "content/kb.aspose.org"
    reference: "content/reference.aspose.org"
    blog: "content/blog.aspose.org"
  localization:
    mode_by_section:
      products: "dir"
      docs: "dir"
      kb: "dir"
      reference: "dir"
      blog: "filename"
```

### `llm`

```yaml
llm:
  api_base_url: "http://localhost:11434"
  model: "claude-sonnet-4.5"
  decoding:
    temperature: 0.0  # Deterministic: always 0.0
    top_p: 1.0
    max_tokens: 4096
  request_timeout_s: 120
  max_concurrency: 4
  fallback:  # Optional
    api_base_url: "https://api.openai.com/v1"
    model: "gpt-4o"
    request_timeout_s: 300
```

### `mcp`

```yaml
mcp:
  enabled: true
  listen_host: "127.0.0.1"
  listen_port: 8787
  auth_token_env: "MCP_AUTH_TOKEN"  # Optional
```

### `telemetry`

```yaml
telemetry:
  endpoint_url: "http://localhost:8765"
  project: "foss-launcher"
  run_tags: ["production", "pilot"]
  auth_token_env: "TELEMETRY_TOKEN"  # Optional
```

### `commit_service`

```yaml
commit_service:
  endpoint_url: "https://commit-service.aspose.org"
  github_token_env: "GITHUB_TOKEN"
  commit_message_template: "docs({section}): {product} - {count} pages"
  commit_body_template: "Generated by FOSS Launcher\n\n{pages_summary}"
  author_name: "FOSS Launcher Bot"
  author_email: "bot@aspose.org"
```

### `budgets`

```yaml
budgets:
  max_runtime_s: 3600  # 1 hour
  max_llm_calls: 1000
  max_llm_tokens: 500000
  max_file_writes: 500
  max_patch_attempts: 5
  max_lines_per_file: 500
  max_files_changed: 100
```

## Examples

### Minimal Pilot Config

```yaml
schema_version: "1.0.0"
product_slug: "pilot-aspose-note-python"
product_name: "Aspose.Note for Python"

  - docs
  - reference

  content_root: "content"
  subdomain_roots:
    docs: "content/docs.aspose.org"
    reference: "content/reference.aspose.org"
allowed_paths:
  - "content/docs.aspose.org/note/python/"
  - "content/reference.aspose.org/note/python/"

  api_base_url: "http://localhost:11434"

  enabled: true

  listen_port: 8787

  endpoint_url: "http://localhost:8765"

  commit_body_template: "Generated by FOSS Launcher"

  max_runtime_s: 3600
```

## Validation Profiles

| Profile | Use Case | Gate Strictness | Timeouts |
|---------|----------|-----------------|----------|
| `local` | Developer feedback | Skip external links, warnings don't fail | Relaxed (e.g., Hugo build: 300s) |
| `ci` | Continuous integration | All gates including external links | Moderate (e.g., Hugo build: 600s) |
| `prod` | Production PR | Maximum rigor, zero tolerance | Longest (e.g., 600s+) |

See [`specs/09_validation_gates.md`](../specs/09_validation_gates.md) for full gate specifications.
