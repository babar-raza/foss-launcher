## Objective

Create role-specific required section lists so every tutorial has prerequisites, every
api_reference has method reference, etc. The outline pass reads these constraints and
enforces them in the LLM prompt.

## Background

Currently the outline LLM freely generates any sections it wants. Tutorial pages end up without
prerequisites; api_reference pages lack method reference tables. A YAML config specifying required
and optional sections per role, injected into the outline prompt, fixes this with zero LLM changes.

## Changes to `multi_pass.py`

In `_generate_outline()` (or equivalent outline generation method), add template loading before
the LLM call:

```python
import yaml as yaml_mod
from pathlib import Path

def _load_section_template(page_role: str) -> dict:
    """Load required/optional sections for a page role."""
    template_path = Path(__file__).parent / "section_templates.yaml"
    try:
        with open(template_path, "r", encoding="utf-8") as f:
            templates = yaml_mod.safe_load(f)
        return templates.get(page_role, templates.get("default", {}))
    except Exception:
        return {}

# In _generate_outline():
page_role = page.get("page_role", "default")
template = _load_section_template(page_role)
required = template.get("required_sections", [])
optional = template.get("optional_sections", [])

if required:
    template_instruction = (
        "\n\nREQUIRED sections (must ALL appear in the outline):\n"
        + "\n".join(f"- {s.replace('_', ' ').title()}" for s in required)
    )
    if optional:
        template_instruction += (
            "\n\nOPTIONAL sections (include if relevant to the content):\n"
            + "\n".join(f"- {s.replace('_', ' ').title()}" for s in optional)
        )
    # Append template_instruction to the outline user message
    user_message += template_instruction
```

**IMPORTANT**: Read `multi_pass.py` first to find the actual outline generation method and how
`user_message` is constructed. Adapt the integration to the real code structure.
