## Objective

Consolidate multiple code fences in getting-started Quick Start Example into ONE unified code block with numbered step comments inside.

## Required spec references

- specs/08_section_writer.md: Code example requirements

## Scope

- Replace separate per-snippet code fences with single consolidated fence
- Add numbered step descriptions as comments inside the code block

## Inputs

- snippet_catalog with multiple code snippets

## Outputs

- Single code fence containing all snippets with step comments

## Allowed Paths

- `src/launch/workers/w5_section_writer/generators/content_generators.py`
- `tests/unit/workers/test_w5_specialized_generators.py`
- `plans/taskcards/TC-2337.md`

## Implementation Steps

1. Find the Quick Start Example section in generate_getting_started_content()
2. Replace separate fences with consolidated approach
3. Add step number and description as comments
4. Test with multiple snippets

## Failure Modes

1. Empty snippet code -> filter out empty snippets
2. Mixed languages -> use first snippet language for all
3. Missing description -> use "Example N" fallback
