### 5. Create worker.py — Orchestrator entry point
```python
def execute_seo_optimizer(
    run_dir: Path,
    run_config: Dict[str, Any],
    product_facts: Optional[Dict] = None,
    page_plan: Optional[Dict] = None,
    **kwargs,
) -> Dict[str, Any]:
    """W6 SEO Optimizer: post-process all final .md files.

    Steps:
    1. Check seo_enabled flag (default: true)
    2. Research keywords once for the product (cached)
    3. For each .md file in site/content/:
       a. Extract page-specific keywords from content
       b. Merge with research keywords (per-page + global)
       c. Inject keywords naturally into prose (optional, if density < 1%)
       d. Optimize SEO metadata in frontmatter
       e. Write back optimized .md
    4. Generate seo_report.json with keyword coverage, density stats, metadata completeness

    Returns:
        {
            "status": "ok" | "disabled" | "skipped",
            "pages_optimized": int,
            "report": {...}
        }
    """
    seo_enabled = run_config.get("seo_enabled", True)
    if not seo_enabled:
        return {"status": "disabled"}

    # Load artifacts
    if product_facts is None:
        product_facts = _load_artifact(run_dir, "product_facts.json")
    if page_plan is None:
        page_plan = _load_artifact(run_dir, "page_plan.json")

    # Research keywords (cached)
    cache = SEOCache(run_dir / "work" / "seo_cache.json")
    keywords_data = cache.get_or_compute(
        f"keywords_{product_facts['product_name']}_{run_config['target_platform']}",
        lambda: research_keywords(...),
        ttl=3600,
    )

    # Process all .md files
    content_dir = run_dir / "work" / "site" / "content"
    md_files = list(content_dir.rglob("*.md"))

    optimized_count = 0
    for md_file in md_files:
        content = md_file.read_text(encoding="utf-8")

        # Extract page-specific keywords
        page_keywords = extract_keywords(content, max_keywords=8)

        # Merge with research keywords
        merged_keywords = _merge_keywords(page_keywords, keywords_data, slug)

        # Inject keywords (optional)
        if run_config.get("seo_inject_keywords", False):
            content = inject_keywords_naturally(content, merged_keywords)

        # Optimize metadata
        content = optimize_seo_metadata(content, page, merged_keywords, ...)

        # Write back
        md_file.write_text(content, encoding="utf-8")
        optimized_count += 1

    # Generate report
    report = {...}
    (run_dir / "work" / "seo_report.json").write_text(json.dumps(report, indent=2))

    return {"status": "ok", "pages_optimized": optimized_count, "report": report}
```

## Failure modes
### FM1: pytrends import fails in production
Detection signal: ImportError when trying to import pytrends.
Resolution steps: Gracefully fall back to offline mode, log warning.
Spec/Gate link: plans/hazy-riding-gizmo.md R17-015 (offline fallback required)

### FM2: Keyword injection breaks code blocks
Detection signal: Code blocks contain injected keywords making them invalid.
Resolution steps: Skip code blocks, headings, and inline code when injecting.
Spec/Gate link: specs/21_worker_contracts.md (content integrity)

### FM3: SEO metadata overwrites existing valid values
Detection signal: Manually-set canonical URLs or descriptions are replaced.
Resolution steps: Only inject fields if not already present (skip existing).
Spec/Gate link: plans/taskcards/00_TASKCARD_CONTRACT.md (no manual content overwrites)
