## Objective

Move the `optimize_seo` node to run BEFORE `review_content` in the LangGraph pipeline.
Currently SEO runs after LinkerPatcher — wrong order. W7 ContentReviewer should see
SEO-optimized content, not raw draft content.

## Current (wrong) edge sequence

```
draft_sections → review_content → [conditional] → link_and_patch → optimize_seo → validate
```

## New (correct) edge sequence

```
draft_sections → optimize_seo → review_content → [conditional] → link_and_patch → validate
```

## Implementation

**File**: `src/launch/orchestrator/graph.py`

**IMPORTANT**: LangGraph edges are declarative — you cannot call `remove_edge()`.
Read the file first to see the exact add_edge calls, then make surgical replacements.

**Edit 1**: Change `draft_sections → review_content` edge to route through SEO:
```python
# BEFORE (find this exact pattern):
graph.add_edge("draft_sections", "review_content")

# AFTER:
graph.add_edge("draft_sections", "optimize_seo")
graph.add_edge("optimize_seo", "review_content")
```

**Edit 2**: Remove the old `link_and_patch → optimize_seo → validate` chain:
```python
# BEFORE (find these lines):
graph.add_edge("link_and_patch", "optimize_seo")
graph.add_edge("optimize_seo", "validate")

# AFTER:
graph.add_edge("link_and_patch", "validate")
```

The re-draft loop (`redraft_pages → draft_sections → optimize_seo → review_content`) is
automatically correct after this change: re-draft runs SEO before the next review pass.
