## Objective

Register a dedicated `howto_article` generator for KB how-to articles with step-by-step instructions and complete code examples.

## Required spec references

- specs/07_section_templates.md: Page role definitions

## Scope

- Create howto_article.txt prompt
- Add generate_howto_article_content() and fallback
- Register with aliases=["how_to", "howto"]

## Inputs

- product_facts with claims
- snippet_catalog
- page with title, purpose

## Outputs

- Markdown with: Overview, When to Use, Step-by-Step Guide, Code Example, Related Links

## Allowed Paths

- `src/launch/workers/w5_section_writer/generators/content_generators.py`
- `src/launch/workers/w5_section_writer/generators/__init__.py`
- `src/launch/workers/w5_section_writer/prompts/howto_article.txt`
- `tests/unit/workers/test_tc_440_section_writer.py`
- `plans/taskcards/TC-2346.md`

## Implementation Steps

1. Create howto_article.txt prompt
2. Add generate_howto_article_content() function
3. Add _build_deterministic_howto_article() fallback
4. Register in __init__.py
5. Add unit tests

## Failure Modes

1. No claims for page -> fallback generates generic steps
2. No snippets -> fallback generates placeholder code
3. Missing title -> uses slug as fallback

- [ ] Step-by-step guide present in output
- [ ] Code example present

- [ ] Registry has all aliases

- [ ] Handles empty claims gracefully
