## Objective

Add an LLM-based detect+fix pass to W7 that runs before the existing 36-check
cycle (Phase 0). LLM simultaneously detects and fixes 7 formatting defect types
in a single API call per page. Fixes are applied to draft files on disk so the
existing checks run on improved content. No regex. Gracefully skips if
llm_client is unavailable.

## Required spec references

- specs/21_worker_contracts.md: W7 worker contract
- specs/08_section_writer.md: Content quality requirements

## Defect types detected and fixed (FQ-1 through FQ-7)

1. FQ-1 NAKED_CODE — Python/bash code outside ``` fences
2. FQ-2 FAQ_CONCAT — FAQ answer + next question on same line
3. FQ-3 TRUNCATED — Bullet ending mid-sentence (trailing comma, preposition)
4. FQ-4 DOUBLE_HEADING — H2 heading + paragraph on same line
5. FQ-5 KEYWORD_COLON — Colon in YAML keywords array item
6. FQ-6 CLAIM_COMMENT — `<!-- claim: UUID -->` visible in body
7. FQ-7 INCOHERENT — Structurally broken sentence/bullet
