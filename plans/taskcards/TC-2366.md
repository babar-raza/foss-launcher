## Objective

Replace W4's bucket-based claim assignment (assign all claims by section/role) with
relevance-ranked assignment using TF-IDF cosine similarity from the existing
`embeddings.py` module. Each page receives the top-K claims most semantically
relevant to its `purpose` string, up to the role's `claim_quota.max`.

**Root cause (RCA H4)**: Claims are currently assigned by section bucket regardless
of whether they match the page's actual topic. A tutorial page gets all workflow
claims from W2, not the workflow claims that are topically closest to that tutorial.

## Scope

### In scope

- Add `select_claims_by_similarity()` function in
  `src/launch/workers/w4_ia_planner/worker.py`:
  - Accepts `purpose: str`, `candidates: List[Dict]`, `top_k: int`
  - Computes TF-IDF cosine similarity between purpose string and each candidate's
    `claim_text`
  - Returns the top-K candidates sorted by descending similarity
- Update call sites in `plan_pages_for_section()` / `generate_optional_pages()`
  that currently do bucket assignment to call `select_claims_by_similarity()` instead
  (with `top_k = strategy["claim_quota"]["max"]`)

  bucket assignment (backwards compat)

### Out of scope

- Changing `assign_page_role()` (that is TC-2364)
- Requiring `source_section` from TC-2365 (similarity works without it)
- Modifying any W5 or W7 gates

## Inputs

- `purpose: str` — from `page_plan["pages"][i]["purpose"]`
- `candidates: List[Dict]` — claim dicts with `claim_text` field
- `top_k: int` — max claims to return

## Outputs

- `List[Dict]` — top-K claim dicts ordered by descending cosine similarity

## Implementation steps

1. Add `select_claims_by_similarity()` near the top of `worker.py` (after imports):
   ```python
   def select_claims_by_similarity(
       purpose: str,
       candidates: List[Dict[str, Any]],
       top_k: int,
   ) -> List[Dict[str, Any]]:
       """Select top-K claims most relevant to the page purpose via TF-IDF cosine similarity.

       Falls back to returning candidates[:top_k] if embeddings unavailable or empty.
       """
       if not candidates or not purpose:
           return candidates[:top_k]
       try:
           from ..w2_facts_builder.embeddings import tokenize, compute_idf, compute_tfidf_vector, cosine_similarity
       except ImportError:
           return candidates[:top_k]

       purpose_tokens = tokenize(purpose)
       claim_token_lists = [tokenize(c.get("claim_text", "")) for c in candidates]
       all_docs = [purpose_tokens] + claim_token_lists
       idf = compute_idf(all_docs)
       purpose_vec = compute_tfidf_vector(purpose_tokens, idf)

       scored = []
       for claim, tokens in zip(candidates, claim_token_lists):
           claim_vec = compute_tfidf_vector(tokens, idf)
           score = cosine_similarity(purpose_vec, claim_vec)
           scored.append((score, claim))

       scored.sort(key=lambda x: x[0], reverse=True)
       return [c for _, c in scored[:top_k]]
   ```

2. Find the existing claim assignment logic in `plan_pages_for_section()` and
   `generate_optional_pages()` — where claim IDs are collected into a page's
   `required_claim_ids`. Replace the bucket-based collection with a call to
   `select_claims_by_similarity(page["purpose"], bucket_candidates, top_k)`.

3. Preserve backwards compat: if the similarity function returns empty (all zeros),
   fall back to first-K from bucket.

4. Add 4 unit tests:
   - `test_select_claims_by_similarity_returns_top_k`: 10 claims, purpose "installation
     guide", verify top-3 returned are installation-related
   - `test_select_claims_by_similarity_empty_candidates`: empty list → empty result
   - `test_select_claims_by_similarity_empty_purpose`: empty purpose → first-K fallback
   - `test_select_claims_by_similarity_fewer_than_k`: 2 candidates, top_k=5 → returns 2

## Acceptance criteria

- All existing W4 tests still pass
- 4 new tests pass
- `select_claims_by_similarity("", [], 5)` returns `[]` (graceful empty)
- `select_claims_by_similarity(purpose, candidates, top_k)` with real data returns
  semantically relevant claims first
