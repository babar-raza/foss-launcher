## Objective

`run_llm_format_fix()` in `llm_format_fix.py` runs 100% sequentially with no per-call timeout.
Each page makes one `chat_completion()` call with `max_tokens=8192` (returns full corrected page).
On local gemma3:12b (~10–30 tok/s): ~4–14 min/page × 21 pages = ~84–294 min for Phase 0 alone —
completely negating the W5 parallelization gains from TC-2362.

Two targeted fixes:
1. **`_FORMAT_FIX_TIMEOUT_S = 120`** per-call timeout cap (matching `_SEMANTIC_TIMEOUT_S = 30`
   pattern from `semantic_accuracy.py:23`, but longer since Phase 0 returns full corrected pages).
2. **`n_workers` param** + `ThreadPoolExecutor` wrapping the per-page loop, using the existing
   `max_parallel_workers_w7` config key (no new config key needed — already computed at `worker.py:285`).

**Expected gain**: 21 pages / 4 workers × 120s cap ≈ **~12 min max** (vs. ~84–294 min).

## Implementation

### `llm_format_fix.py` changes

Add after logger line:
```python
_FORMAT_FIX_TIMEOUT_S: int = 120  # Per-call cap for Phase 0 (full page, max_tokens=8192)
```

Add `n_workers` param and parallel path to `run_llm_format_fix()`:
```python
def run_llm_format_fix(
    drafts_dir: Path,
    llm_client: Optional[Any],
    n_workers: int = 1,
) -> Tuple[List[Dict[str, Any]], List[Dict[str, Any]]]:
    ...
    draft_files = sorted(drafts_dir.rglob("*.md"))
    effective = min(n_workers, len(draft_files)) if n_workers > 1 and draft_files else 1

    if effective <= 1:
        for draft_path in draft_files:
            issues, fix = _process_one_page(draft_path, system_text, llm_client)
            all_issues.extend(issues)
            if fix is not None:
                fix_results.append(fix)
    else:
        from concurrent.futures import ThreadPoolExecutor, as_completed
        with ThreadPoolExecutor(max_workers=effective, thread_name_prefix="w7_fmt_fix") as pool:
            futures = {pool.submit(_process_one_page, dp, system_text, llm_client): dp for dp in draft_files}
            for fut in as_completed(futures):
                try:
                    issues, fix = fut.result()
                except Exception as exc:
                    logger.warning("[W7/P0] format fix failed for %s: %s", futures[fut].name, exc)
                    issues, fix = [], None
                all_issues.extend(issues)
                if fix is not None:
                    fix_results.append(fix)
```

Add `timeout=_FORMAT_FIX_TIMEOUT_S` to `chat_completion()` in `_process_one_page()`:
```python
response = llm_client.chat_completion(
    messages=[...],
    call_id=f"w7_format_fix_{draft_path.stem}",
    temperature=0.0,
    max_tokens=8192,
    timeout=_FORMAT_FIX_TIMEOUT_S,
)
```
