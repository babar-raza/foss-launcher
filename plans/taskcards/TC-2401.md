## Objective

Parallelize the per-section LLM draft loop in `MultiPassOrchestrator._generate_draft_per_section()`.
Currently ~5 sections per page are generated sequentially (110 LLM calls for 22 pages). By running
all sections within a page concurrently via `ThreadPoolExecutor`, W5 wall-clock time reduces by 3–4×.

Config key `max_parallel_sections` (default: 1 = sequential, backwards compatible). Set to 5 in
pilot run configs to enable.

### Step 1: Add import

### Step 2: Read config in __init__

```python
if isinstance(run_config, dict):
    self._use_json_draft: bool = run_config.get("use_json_draft", True)
    self._per_section_draft: bool = run_config.get("per_section_draft", True)
    self._section_parallelism: int = max(1, int(run_config.get("max_parallel_sections", 1)))
else:

    self._per_section_draft = True
    self._section_parallelism = 1
```

### Step 3: Add parallel path to section draft loop

In `_generate_draft_per_section()` (the method containing the `for i, section_spec in enumerate(sections):` loop), immediately BEFORE the sequential `for` loop, add:

```python
if self._section_parallelism > 1 and len(sections) > 1:
    # Parallel path: all sections drafted concurrently.
    # No prev_section_summary chain — each starts with empty context.
    # Results are assembled in original section order after all futures complete.
    _llm = self.llm_client
    _source_chunks = self._source_chunks
    _page_idx = _page_idx  # captured from outer scope

    def _draft_section_parallel(i_spec):
        """Draft one section. Captured: combined_system, all_page_claims, all_snippets, page, slug."""
        _i, _spec = i_spec
        _heading = _spec.get("heading", f"Section {_i + 1}")
        _claim_ids = _spec.get("claim_ids", [])
        _sec_claims = _get_section_claims(_claim_ids, all_page_claims, page_index=_page_idx + _i)
        _sec_snippets = _get_section_snippets(_sec_claims, all_snippets)
        _claim_lines = "\n".join(
            f"- [{c.get('claim_id', '')}] {c.get('claim_text', '')}" for c in _sec_claims
        )
        _snippet_text = ""
        if _sec_snippets:
            _snippet_text = "\n\nCode snippets:\n" + "\n".join(
                f"```{s.get('language', 'python')}\n{s.get('code', '')[:200]}\n```"
                for s in _sec_snippets
            )
        _level = _spec.get("level", 2)
        _user_msg = (
            f'Write the "{_heading}" section as JSON with this exact structure:\n'
            f'{{"heading": "{_heading}", "level": {_level}, '
            f'"body": "prose with <!-- claim: id --> markers", '
            f'"claim_ids_used": ["claim-id"], '
            f'"code_blocks": [{{"language": "python", "code": "...", "caption": "..."}}]}}\n\n'
            f"Claims to cover:\n{_claim_lines}"
            + _snippet_text
        )
        if _source_chunks:
            try:
                from launch.workers.w2_facts_builder.chunk_sources import retrieve_relevant_chunks
                _query = _heading + " " + " ".join(c.get("claim_text", "") for c in _sec_claims[:3])
                _chunks = retrieve_relevant_chunks(_query, _source_chunks, top_k=3)
                if _chunks:
                    _user_msg += "\n\nSource material for grounding:\n" + "\n\n---\n".join(
                        c["text"][:300] for c in _chunks
                    )
            except Exception:
                pass
        try:
            _resp = _llm.chat_completion(
                messages=[
                    {"role": "system", "content": combined_system},
                    {"role": "user", "content": _user_msg},
                ],
                call_id=f"mp_section_{slug}_{_i}",
                temperature=0.1,
                max_tokens=max(1500, page.get("effective_token_budget", 2048) // max(1, len(sections))),
                response_format={"type": "json_object"},
            )
            _raw = _resp.get("content", "")
            _sec_json = parse_json_draft(_raw)
            if _sec_json and isinstance(_sec_json, dict):
                _sec_json.setdefault("heading", _heading)
                _sec_json.setdefault("level", _level)
                _body = _sec_json.get("body", "")
                if _body:
                    _sec_json["body"] = _trim_truncated_ending(_body)
                return _i, _sec_json
            else:
                return _i, {
                    "heading": _heading, "level": _level,
                    "body": _raw[:500] if _raw else f"Content for {_heading}.",
                    "code_blocks": [],
                }
        except Exception as _e:
            logger.error("Section parallel draft failed for '%s': %s", _heading, _e)
            return _i, {
                "heading": _heading, "level": _level,
                "body": "\n".join(
                    f"<!-- claim: {c.get('claim_id', '')} --> {c.get('claim_text', '')}"
                    for c in _sec_claims
                ),
                "code_blocks": [],
            }

    _n_workers = min(len(sections), self._section_parallelism)
    _results: dict = {}
    with ThreadPoolExecutor(max_workers=_n_workers, thread_name_prefix="sec_draft") as _pool:
        _futures = {_pool.submit(_draft_section_parallel, (i, spec)): i
                    for i, spec in enumerate(sections)}
        for _fut in as_completed(_futures):
            _idx, _sec = _fut.result()
            _results[_idx] = _sec
    assembled_sections = [_results[i] for i in range(len(sections))]

else:
    # Sequential path (original behavior) — with prev_section_summary chain.
    # (existing for loop follows unchanged)
```

After the parallel block, keep the existing `for i, section_spec in enumerate(sections):` loop
unchanged as the sequential path (it now sits inside the `else` branch).

### Step 4: Determinism guarantee

The parallel path collects results into `_results: dict` keyed by index, then assembles via
`[_results[i] for i in range(len(sections))]`. This guarantees section order is deterministic
regardless of which future completes first.

## Failure modes

1. **Thread exception propagates incorrectly** — Detection: `fut.result()` re-raises the exception
   from the worker thread. Resolution: inner `try/except` in `_draft_section_parallel` catches all
   exceptions and returns a deterministic fallback dict. No exception escapes the closure.
   Link: specs/34_strict_compliance_guarantees.md Guarantee E.

2. **prev_section_summary quality drop** — Detection: W7 content quality score drops vs baseline.
   Resolution: `prev_section_summary` provides only 100 chars of prior context; the outline
   (injected in `combined_system`) already provides full structural context. If quality drops are
   detected in pilots, set `max_parallel_sections: 1` to revert. Link: specs/21_worker_contracts.md.

3. **LLM concurrency spike without semaphore** — Detection: 429 rate limit errors in evidence logs.
   Resolution: TC-2400 semaphore (`max_concurrency: 4`) limits total concurrent LLM calls across
   all threads. Combined with `max_parallel_pages`, total concurrent section calls ≤
   `max_parallel_pages × max_parallel_sections`. Ensure `max_concurrency ≥ max_parallel_pages × 1`
   in run_config. Link: specs/34_strict_compliance_guarantees.md Guarantee E.

4. **ThreadPoolExecutor thread leak** — Detection: Python ResourceWarning on interpreter exit.
   Resolution: `with ThreadPoolExecutor(...) as _pool:` context manager guarantees `shutdown(wait=True)`
   on exit. Link: Python `concurrent.futures` docs.
