# TC-1616: W2 Claim Quality Filter - Reduce key_features Noise

## Objective

Reduce noise in `key_features` claim group from 50% to <20% by implementing four targeted filters:
1. Lower `_is_code_like()` threshold from 40% to 25% non-alpha ratio
2. Add `_is_template_claim()` filter to detect and reclassify template-generated claims
3. Cap code-grounded claims at 15 with relevance scoring
4. Fix source quality filter to deprioritize `source_type: "source_code"` for key_features

**Current State**: 35 key_features with 50% noise (21 noisy claims):
- Template claims: "Provides the X class for X operations"
- Code snippets leaked through filters
- API descriptions with heavy identifier content

**Target State**: 18-22 key_features with 80%+ usable quality (only 3-4 noise)

Add new function:

def _is_template_claim(text: str, product_name: str = "") -> bool:
    """
    Detect template-generated claims that are too generic for key_features.

    Examples:
    - "{product} provides the {ClassName} class for {classname} operations"
    - "The {ClassName} class provides methods: {method1}(), {method2}()"
    - "{product} provides the {x}() function"

    Returns:
        True if the text matches template patterns
    """
    import re

    text_lower = text.lower()

    # Template patterns to detect
    template_patterns = [
        r'provides? the \w+ class for \w+ operations',
        r'the \w+ class provides? methods?:',
        r'provides? the \w+\(\) function',
        r'provides? \d+ (classes?|functions?|methods?)',
        r'aspose[-.]\w+ provides? the',
    ]

    for pattern in template_patterns:
        if re.search(pattern, text_lower):
            return True

    return False
```

### Step 5: Fix source quality filter

**File**: `src/launch/workers/w2_facts_builder/worker.py`
**Function**: `_is_low_quality_source()` (line ~425-438)

def _is_low_quality_source(claim):
    """Check if claim comes from meta/implementation docs or low-quality code sources."""
    st = claim.get('source_type', '')
    claim_kind = claim.get('claim_kind', '')

    # Source code is low quality for key_features/features, OK for api_reference
    if st == 'source_code':
        if claim_kind in ('key_feature', 'feature'):
            return True  # Deprioritize for marketing content
        # Allow for api_reference (intentional)

    # Existing meta/implementation doc checks
    if st in ('implementation_doc', 'meta'):
        return True

    # Fallback: check citation paths when source_type is missing
    if not st:
        for cit in claim.get('citations', []):
            path = cit.get('path', '').lower().replace('\\', '/')
            if any(m in path for m in _META_CITATION_MARKERS):
                return True
            if any(m in path for m in _IMPL_CITATION_MARKERS):
                return True

    return False
```
