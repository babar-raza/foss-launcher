## Objective

Parallelize two sequential LLM call loops in W2 FactsBuilder:

1. **Workflow step enrichment** (`for wf in workflows: llm_generate_workflow_steps(wf)`) — one
   LLM call per qualifying workflow (typically 1–5 calls). Parallelized by extracting the LLM
   call into a thread, applying mutations back in the main thread after `as_completed`.

2. **Example enrichment** (`for example_file in example_files: enrich_example(...)`) — one call
   per example file (typically 5–30 files). Already pure (returns dict, no mutation); fully
   parallelizable.

Both reuse the existing `max_parallel_batches` run_config key (default 4). No new config key
or schema change required.

- `specs/21_worker_contracts.md` — W2 FactsBuilder artifact contract

## Implementation

### Example enrichment

Replace sequential loop (lines 1064–1078):
```python
for i, example_file in enumerate(example_files):
    example_file['example_id'] = f"example_{i+1}"
    example_file['primary_snippet_id'] = f"snippet_{i+1}"
    try:
        enriched = enrich_example(example_file, example_repo_dir, claims)
        example_inventory.append(enriched)
    except Exception as e:
        ...
        example_inventory.append({fallback})
```

With parallelized version:
```python
# Pre-assign IDs (fast, sequential — mutates dicts before threads read them)
for i, example_file in enumerate(example_files):
    example_file['example_id'] = f"example_{i+1}"
    example_file['primary_snippet_id'] = f"snippet_{i+1}"

n_ex = min(len(example_files), run_config.get("max_parallel_batches", 4) if run_config else 4)
if n_ex <= 1 or len(example_files) <= 1:
    for example_file in example_files:
        try:
            example_inventory.append(enrich_example(example_file, example_repo_dir, claims))
        except Exception as e:
            ...
else:
    from concurrent.futures import ThreadPoolExecutor, as_completed
    _ex_results: dict[int, Any] = {}
    with ThreadPoolExecutor(max_workers=n_ex, thread_name_prefix="ex_enrich") as pool:
        futures = {pool.submit(enrich_example, ef, example_repo_dir, claims): i
                   for i, ef in enumerate(example_files)}
        for fut in as_completed(futures):
            idx = futures[fut]
            try:
                _ex_results[idx] = fut.result()
            except Exception as e:
                logger.warning(f"Failed to enrich example: {e}")
                ef = example_files[idx]
                _ex_results[idx] = {
                    'example_id': ef.get('example_id'),
                    'title': ef.get('path', '').split('/')[-1],
                    'tags': ef.get('tags', []),
                    'primary_snippet_id': ef.get('primary_snippet_id'),
                }
    example_inventory = [_ex_results[i] for i in range(len(example_files))]
```

### Workflow step enrichment

Pre-filter qualifying workflows, then parallelize the `llm_generate_workflow_steps` LLM call.
Mutations are applied sequentially in the main thread after `as_completed` to avoid race conditions
on `claims` list and `wf` dict.

```python
if llm_client is not None:
    from .extract_claims import llm_generate_workflow_steps, compute_claim_id
    from concurrent.futures import ThreadPoolExecutor, as_completed as _as_completed

    # Filter to workflows needing enrichment
    _pending_wfs = []
    for wf in workflows:
        tag = wf.get('workflow_tag', '')
        if tag not in LLM_WORKFLOW_THRESHOLDS:
            continue
        min_steps, target_steps = LLM_WORKFLOW_THRESHOLDS[tag]
        if len(wf.get('steps', [])) >= min_steps:
            continue
        _pending_wfs.append((wf, tag, min_steps, target_steps))

    if _pending_wfs:
        def _call_llm_for_wf(wf, tag, target_steps):
            existing = [s.get('name', '') for s in wf.get('steps', [])]
            return wf, tag, llm_generate_workflow_steps(
                workflow_tag=tag,
                workflow_title=wf.get('title', tag),
                existing_steps=existing,
                api_surface=api_surface_summary,
                positioning=code_analysis.get('positioning', {}),
                product_name=product_name,
                llm_client=llm_client,
                target_steps=target_steps,
            )

        n_wf = min(len(_pending_wfs), run_config.get("max_parallel_batches", 4) if run_config else 4)
        with ThreadPoolExecutor(max_workers=n_wf, thread_name_prefix="wf_enrich") as pool:
            futures = [
                pool.submit(_call_llm_for_wf, wf, tag, target_steps)
                for wf, tag, _min_steps, target_steps in _pending_wfs
            ]
            for fut in _as_completed(futures):
                try:
                    wf, tag, new_steps = fut.result()
                    if new_steps:
                        current_steps = wf.get('steps', [])
                        max_step_num = max((s.get('step_num', 0) for s in current_steps), default=0)
                        for i, ns in enumerate(new_steps, start=1):
                            step_num = max_step_num + i
                            claim_text = ns.get('claim_text', ns.get('name', f'Step {step_num}'))
                            claim_kind = 'workflow'
                            claim_id = compute_claim_id(claim_text, claim_kind, product_name)
                            claims.append({'claim_id': claim_id, 'claim_text': claim_text,
                                           'claim_kind': claim_kind, 'truth_status': 'inference',
                                           'confidence': 'medium', 'source_type': 'llm_synthesized',
                                           'citations': [], 'step_order': step_num})
                            wf['steps'].append({'step_num': step_num, 'step_id': f'step_{step_num}',
                                                'name': claim_text, 'claim_id': claim_id, 'snippet_id': None})
                            wf['claim_ids'].append(claim_id)
                        total = len(wf['steps'])
                        wf['complexity'] = 'simple' if total <= 3 else ('moderate' if total <= 6 else 'complex')
                        wf['estimated_time_minutes'] = 5 + (total - 1) * 2
                        logger.info("llm_workflow_steps_generated", workflow_tag=tag,
                                    existing_steps=len(current_steps), new_steps=len(new_steps),
                                    total_steps=len(wf['steps']))
                except Exception as e:
                    logger.warning("llm_workflow_generation_failed", workflow_tag="unknown", error=str(e))
```

## Failure modes

1. **LLM unavailable for workflow enrichment** — `llm_client is None` check at top; block skipped entirely. Unchanged.
2. **Thread exception in `enrich_example`** — `fut.result()` raises; fallback dict appended. Same as old behavior.
3. **Thread exception in `_call_llm_for_wf`** — `fut.result()` raises; log warning, workflow left with original steps.
4. **`max_parallel_batches` absent from run_config** — `.get(..., 4)` returns 4. Backward-compatible.
5. **`run_config` is None** — guarded: `run_config.get(...) if run_config else 4`. Uses default=4.
