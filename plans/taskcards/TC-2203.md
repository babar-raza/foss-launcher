```python
def _build_page_title(slug: str, section: str, product_name: str, platform: str) -> str:
    """Build unique, SEO-optimized page title.

    Format: "{Page Name} with {Product} for {Platform}" or
            "{Product} {Platform} {Page Name} — {Context}"

    Max length: ~70 chars (SEO best practice)
    Always includes: product_name, platform (when non-empty)
    """
    # Normalize slug to title case
    base_title = slug.replace("-", " ").replace("_", " ").title()

    # Page-specific patterns
    title_patterns = {
        "getting-started": f"Getting Started with {product_name} for {platform}",
        "installation": f"How to Install {product_name} for {platform}",
        "developer-guide": f"{product_name} {platform} Developer Guide",
        "faq": f"{product_name} {platform} FAQ — Common Questions Answered",
        "api-overview": f"{product_name} {platform} API Reference",
        "troubleshooting": f"{product_name} {platform} Troubleshooting Guide",
        "best-practices": f"{product_name} {platform} Best Practices",
        "tutorial": f"{product_name} {platform} Tutorial",
        "overview": f"{product_name} {platform} {section.title()} Overview",
        "index": f"{product_name} {platform} {section.title()}",
    }

    title = title_patterns.get(slug, f"{product_name} {platform} {base_title}")

    # Clean up empty platform
    if not platform:
        title = title.replace("  ", " ").strip()

    # Truncate if needed (rare)
    if len(title) > 70:
        title = title[:67] + "..."

    return title
```

### 2. Create _build_page_description() helper
Add after `_build_page_title()`:

```python
def _build_page_description(
    slug: str,
    section: str,
    product_name: str,
    platform: str,
    purpose: str = ""
) -> str:
    """Build unique, SEO-optimized page description (meta description).

    Max length: 160 chars (SEO best practice)
    Always includes: product_name, platform, specific page content hint
    """
    # Base patterns with product and platform
    desc_patterns = {
        "getting-started": f"Learn how to install and use {product_name} for {platform}. Step-by-step guide with code examples.",
        "installation": f"Install {product_name} for {platform} via pip, conda, or source. Requirements, setup, and verification.",
        "developer-guide": f"Comprehensive {product_name} {platform} developer guide with code examples and usage scenarios.",
        "faq": f"Frequently asked questions about {product_name} for {platform}. Common issues, solutions, and tips.",
        "api-overview": f"{product_name} {platform} API reference. Classes, methods, modules, and code examples.",
        "troubleshooting": f"Troubleshoot common {product_name} {platform} errors. Solutions, workarounds, and debugging tips.",
    }

    desc = desc_patterns.get(slug)

    # Fallback to purpose if no pattern match
    if not desc:
        if purpose:
            desc = f"{product_name} for {platform}: {purpose}"
        else:
            desc = f"{product_name} for {platform} {slug.replace('-', ' ')} documentation and resources."

    # Clean up empty platform
    if not platform:
        desc = desc.replace("  for ", " ").replace("  ", " ").strip()

    # Truncate to 160 chars
    if len(desc) > 160:
        desc = desc[:157] + "..."

    return desc
```

## Failure modes
### FM1: Title/description duplication
Detection signal: Multiple pages have identical titles or descriptions.
Resolution steps: Add more specific patterns for each slug, include section context.
Spec/Gate link: plans/hazy-riding-gizmo.md R17-014 (uniqueness requirement)

### FM2: SEO length violations
Detection signal: Titles > 70 chars or descriptions > 160 chars.
Resolution steps: Aggressive truncation with "..." suffix.
Spec/Gate link: SEO best practices (title 60-70, description 150-160)

### FM3: Missing product/platform in metadata
Detection signal: Titles or descriptions don't include product name or platform.
Resolution steps: Ensure all patterns include `{product_name}` and `{platform}` placeholders.
Spec/Gate link: specs/32_platform_aware_layout.md (platform-specific URLs)
