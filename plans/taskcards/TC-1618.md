## Problem Statement

**Current Problem**: 0% marketing content — no use cases, no tutorials, no narratives

The facts builder currently extracts technical claims (features, limitations, workflows) but misses narrative content valuable for blog posts and tutorials. This leaves marketing teams without structured content for promotional materials.

## Objectives

Extract 10-15 use cases and 3-5 tutorials from:
- Untapped README sections ("Use Cases", "Applications", "Scenarios")
- Tutorial structures (prose + code)
- Feature profiles (synthesized use cases)
- LLM-enhanced analysis

## Success Criteria

- [ ] Use cases: 10-15 (5-8 README, 4-6 LLM, 2-3 synthesized)
- [ ] Tutorials: 3-5
- [ ] Use cases have scenario, description, benefit
- [ ] Tutorials preserve prose + code structure
- [ ] All 10 new tests passing
- [ ] 0 test regressions
- [ ] Both pilots show increased use_case/tutorial claims

## Implementation Plan

### 1. Expand Section Headers
**File**: `src/launch/workers/w2_facts_builder/extract_claims.py`

Add 14 new section headers to `_SECTION_HEADERS` constant:
- Use case headers: use cases, applications, when to use, scenarios, real world, case study
- Tutorial headers: examples, tutorial, walkthrough, guide, how to, step by step

### 2. Add Use Case Extraction
**File**: `src/launch/workers/w2_facts_builder/extract_claims.py`

Add `_extract_use_case_narratives()` function with two strategies:
1. Bullet list pattern: "- **Use case name**: description"
2. Narrative paragraphs: 20+ word blocks describing real-world applications

### 3. Add Tutorial Extraction
**File**: `src/launch/workers/w2_facts_builder/extract_claims.py`

Add `_extract_tutorial_narratives()` function:
- Requires both prose (30+ words) AND code blocks
- Preserves educational flow
- Counts code and prose blocks

### 4. Enhance LLM Prompt
**File**: `src/launch/workers/w2_facts_builder/code_understanding.py`

Add to LLM response structure:
- `use_cases` array (scenario, description, benefit, example_domain)
- `real_world_applications` array (industry, use_case, value_proposition)

### 5. Synthesize Use Cases from Feature Profiles
**File**: `src/launch/workers/w2_facts_builder/feature_profiles.py`

Add `_synthesize_use_cases_from_profile()` function:
- Topic-specific templates (import_export, data_processing, etc.)
- Generate 2-3 use cases per high-density topic

### 6. Testing
Add 10 new tests across 3 test files

## Risks & Mitigation

| Risk | Impact | Mitigation |
|------|--------|------------|
| False positives (code as narratives) | Medium | Reuse existing `_is_code_like()` and `_is_prose_like()` filters |
| Tutorial detection too strict | Medium | 30-word threshold balances quality vs recall |
| LLM hallucination in use cases | Low | LLM use cases are supplementary, not primary source |
