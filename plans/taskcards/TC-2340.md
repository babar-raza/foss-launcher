## Objective

Add a visible WARNING log when a page_role is not registered in GeneratorRegistry, and harden the generic fallback prompt with role-aware guidance hints so that pages using the generic path produce higher quality content.

## Required spec references

- specs/07_section_templates.md (Section writing templates, generator dispatch)
- specs/21_worker_contracts.md:195-226 (W5 SectionWriter contract)

## Scope

### In scope

- Add `logger.warning()` in `generate_section_content()` when `gen_registry.has(page_role)` is False, before template/LLM fallback path
- Add role-aware guidance dictionary in `_build_section_prompt()` and prepend role hints to the generic prompt
- Add `page_role` parameter to `_build_section_prompt()` signature
- Unit tests verifying the warning message pattern and role guidance coverage

### Out of scope

- Registering new generators (handled by TC-2330, TC-2331, TC-2332)
- Modifying W7 ContentReviewer
- Modifying any prompts outside `_build_section_prompt()`

## Implementation steps

1. Read worker.py and identify exact insertion points for warning log and role guidance
2. Add `logger.warning()` after the `gen_registry.has(page_role)` block (between line 631 and 633)
3. Add `page_role` parameter to `_build_section_prompt()` function signature with default `""`
4. Add `_role_guidance` dictionary inside `_build_section_prompt()` with hints for 6 common page roles
5. Prepend `ROLE GUIDANCE: {role_hint}` to the assembled prompt before returning
6. Pass `page_role` to `_build_section_prompt()` at the call site (line 772)
7. Add tests verifying the warning message pattern exists in source code
8. Add tests verifying the role guidance dictionary covers key page roles
9. Run tests to confirm no regressions

## Failure modes

1. **Warning log not reached for registered roles**: The warning is placed AFTER the `if gen_registry.has(page_role):` block which returns early. Registered roles will never trigger the warning. Detection: unit test with registered role should not contain warning. Mitigation: placement is correct by design (after return).

2. **_build_section_prompt signature change breaks callers**: Adding `page_role` as a keyword argument with default value `""` ensures backward compatibility. Detection: existing tests still pass. Mitigation: default value prevents breaking existing call sites.

3. **Role guidance prepended to prompt breaks LLM output**: The guidance is a single line prepended before the existing prompt. Detection: existing test_generate_section_content tests still pass. Mitigation: guidance is concise and structured as an instruction, not changing the overall prompt structure.
