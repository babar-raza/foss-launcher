## Objective

Add a declarative tone control system to W5 SectionWriter. Every `generate_*_content()` function
injects a consistent editorial voice and structural constraints into its LLM prompt, based on the
page role and section type.

Reference implementation:
- `C:/Users/prora/OneDrive/Documents/GitHub/content-generator/src/utils/tone_utils.py`
- `C:/Users/prora/OneDrive/Documents/GitHub/content-generator/config/main.yaml` (section_controls)

## Background

The foss-launcher currently has NO tone control. LLM generates inconsistent prose across page types:
tutorials sound like API docs, FAQs are verbose, troubleshooting lacks diagnostic structure. The
content-generator uses a YAML config (section_controls) + a `build_section_prompt_enhancement()`
function that appends editorial constraints to every LLM prompt. This single addition transforms
prose quality significantly.

### `src/launch/workers/w5_section_writer/tone_utils.py`

```python
"""Tone prompt enhancement for W5 SectionWriter.

Adapted from content-generator src/utils/tone_utils.py:37.
Reference: build_section_prompt_enhancement().
"""
import yaml
from pathlib import Path
from typing import Optional

STRUCTURE_DIRECTIVES = {
    "step_by_step": "Use numbered steps. Each step must have exactly one action.",
    "prose_with_subheadings": "Use H3 subheadings every 2-3 paragraphs. Prose only, no bullets.",
    "problem_solution_pairs": (
        "For each problem: H3 heading → symptom description → root cause → solution steps."
    ),
    "qa_pairs": "Format as Q: / A: pairs. Answer must begin with a direct sentence.",
    "segmented_walkthrough": (
        "Use H3 section per workflow stage. Each stage: explanation then code."
    ),
    "bullets_with_description": "Each bullet: **term**: one-sentence description.",
}

_TONE_CONFIG: Optional[dict] = None  # Module-level singleton


def load_tone_config(path: Optional[str] = None) -> dict:
    """Load tone_config.yaml from module directory (cached)."""
    global _TONE_CONFIG
    if _TONE_CONFIG is not None:
        return _TONE_CONFIG
    config_path = Path(path or __file__).parent / "tone_config.yaml"
    try:
        _TONE_CONFIG = yaml.safe_load(config_path.read_text(encoding="utf-8")) or {}
    except Exception:
        _TONE_CONFIG = {}
    return _TONE_CONFIG


def build_section_prompt_enhancement(
    tone_config: dict,
    page_role: str,
    base_prompt: str,
) -> str:
    """Append tone + structure directives to an existing LLM prompt.

    Adapted from content-generator tone_utils.py:37.
    Returns base_prompt unchanged if page_role has no config.
    """
    if not tone_config:
        return base_prompt

    global_voice = tone_config.get("global_voice", {})
    section = tone_config.get("section_controls", {}).get(
        page_role, tone_config.get("section_controls", {}).get("default", {})
    )
    if not section:
        return base_prompt

    pov = global_voice.get("pov", "second_person")
    formality = global_voice.get("formality", "professional_conversational")
    tech_depth = global_voice.get("technical_depth", "intermediate")
    tone = section.get("tone", "informative")
    structure_key = section.get("structure", "prose_with_subheadings")
    structure_directive = STRUCTURE_DIRECTIVES.get(structure_key, "")
    word_count = section.get("word_count_target", "")
    required = section.get("required_elements", [])
    avoid = section.get("avoid_phrases", [])

    pov_map = {
        "second_person": "second person (use 'you', 'your')",
        "first_person": "first person (use 'I', 'we')",
        "third_person": "third person (avoid 'you')",
    }

    required_block = "\n".join(f"- {e}" for e in required) if required else "- (none)"
    avoid_block = ", ".join(f'"{p}"' for p in avoid) if avoid else "(none)"

    enhancement = (
        f"\n\n**TONE AND STYLE:**\n"
        f"- Write in {pov_map.get(pov, pov)} perspective\n"
        f"- Formality: {formality}\n"
        f"- Technical depth: {tech_depth} (assume developer audience)\n"
        f"- Section tone: {tone}\n"
        f"\n**STRUCTURE:**\n"
        f"- {structure_directive}\n"
        + (f"- Target length: {word_count}\n" if word_count else "")
        + f"\n**REQUIRED ELEMENTS (include all):**\n{required_block}\n"
        + f"\n**AVOID** these phrases: {avoid_block}\n"
    )

    return base_prompt + enhancement
```

## Integration in `content_generators.py`

Read `src/launch/workers/w5_section_writer/generators/content_generators.py` first to understand
the current structure. For EACH `generate_*_content()` function:

1. Import at module top: `from launch.workers.w5_section_writer.tone_utils import load_tone_config, build_section_prompt_enhancement`
2. Add module-level singleton: `_TONE_CONFIG = load_tone_config()`
3. In each generator, after building the base prompt, call:
   `prompt = build_section_prompt_enhancement(_TONE_CONFIG, page_role, base_prompt)`

Apply to all generators: tutorial, api_reference, troubleshooting, faq, feature_showcase,
workflow_page, comprehensive_guide, best_practices, getting_started, landing, blog, and any others.
The `page_role` is available from the `page` dict: `page.get("page_role", "default")`.
