## Objective

Add `_compute_token_budget(page, run_config) -> int` to W5 `worker.py`. Read
`page["content_strategy"]["priority_weight"]` (written by W4); fall back to
`SECTION_TYPE_WEIGHTS` dict by page_type. Clamp to [0.5x base, 2.0x base].
Wire into `_generate_single_page()` before LLM call with DEBUG log + manifest field.

## Required spec references

- `specs/21_worker_contracts.md` section Priority-Weighted Token Allocation
- `plans/healing/04_add_priority_weights_to_token_allocation.md`

## Scope

### In scope

## Implementation steps

1. Add `SECTION_TYPE_WEIGHTS` dict at module level in `worker.py` covering 14 page types
   (landing=1.2, tutorial=1.5, api_reference=1.8, faq=0.8, toc=0.5, blog=1.0, etc.)

2. Add `_compute_token_budget(page, run_config) -> int` helper:
   Read priority_weight from content_strategy; fall back to SECTION_TYPE_WEIGHTS by page_type;
   clamp to [0.5, 2.0]; return int(base * weight).

3. In `_generate_single_page()`, before the LLM call:
   compute effective_budget, emit DEBUG log, add `effective_token_budget` to manifest entry.

4. Add 3 unit tests in `tests/unit/workers/test_tc_440_section_writer.py`:
   test_compute_token_budget_from_priority_weight_field,
   test_compute_token_budget_fallback_to_page_type,
   test_compute_token_budget_clamp_at_2x

## Failure modes

### FM-1: priority_weight field absent or malformed

**Detection**: `page["content_strategy"]` absent or `priority_weight` not numeric.
**Resolution**: `_compute_token_budget` handles this with `.get()` chaining; fallback activates automatically.
**Spec/gate link**: specs/21_worker_contracts.md section W5 token allocation

### FM-2: page_type not in SECTION_TYPE_WEIGHTS

**Detection**: `SECTION_TYPE_WEIGHTS.get(page_type, 1.0)` falls through with default 1.0.
**Resolution**: Default weight 1.0 applies without crash.
**Spec/gate link**: specs/21_worker_contracts.md section W5 token allocation

### FM-3: weight outside [0.5, 2.0] after field read

**Detection**: Clamp logic `max(0.5, min(2.0, float(weight)))` catches out-of-range values.
**Resolution**: Clamped silently to boundary; verified by test_compute_token_budget_clamp_at_2x.
**Spec/gate link**: specs/21_worker_contracts.md section W5 token allocation clamp requirement
