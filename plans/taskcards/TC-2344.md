## Objective

Add content strategies and default headings for new page roles (format_conversion, howto_article, feature_blog, performance_guide, blog_announcement) in W4 IAPlanner, aligning with aspose.net content patterns. This enables W5 generators to receive proper strategy metadata for each new page type.

## Required spec references

- specs/05_ia_and_page_plan.md (IA planning contract)
- specs/08_content_distribution_strategy.md (content distribution rules)
- specs/06_page_planning.md (page planning algorithm)

## Scope

### In scope
- Add 3 new page_role strategies to `build_content_strategy()`: format_conversion, howto_article, feature_blog
- Add 5 new entries to `_default_headings_for_role()` headings map: format_conversion, howto_article, feature_blog, performance_guide, blog_announcement
- Unit tests validating new strategies and headings

### Out of scope
- W5 generator implementation (covered by TC-2345, TC-2346, TC-2347)
- Ruleset changes (covered by TC-2348)
- W2 claim detection (covered by TC-2342)

## Inputs
- Existing `build_content_strategy()` elif chain in worker.py
- Existing `_default_headings_for_role()` headings map in worker.py

## Outputs
- Updated `build_content_strategy()` with 3 new page_role branches
- Updated `_default_headings_for_role()` with 5 new entries
- Unit tests for new strategies and headings

## Implementation steps

1. In `build_content_strategy()`, add elif branches for format_conversion, howto_article, and feature_blog before the default fallback `else` block
2. In `_default_headings_for_role()`, add entries to `headings_map` for format_conversion, howto_article, feature_blog, performance_guide, and blog_announcement
3. Add unit tests for each new strategy (verify keys: primary_focus, forbidden_topics, claim_quota, unique_angle, tone)
4. Add unit tests for each new headings entry

## Failure modes

1. **New strategy missing required keys** - Detection: test asserts each strategy has primary_focus, forbidden_topics, claim_quota. Resolution: add missing keys to strategy dict. Spec: specs/08_content_distribution_strategy.md.
2. **Headings map key collision** - Detection: test verifies each role returns distinct heading list. Resolution: ensure unique keys. Gate: page_plan schema validation.
3. **Existing strategies regress** - Detection: existing tests for landing, toc, comprehensive_guide still pass. Resolution: only append new branches, never modify existing ones. Gate: pytest -x.
