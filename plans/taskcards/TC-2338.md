## Objective

Fix `TypeError: unhashable type 'dict'` crash in W7 ContentReviewer scoring when issue locations contain non-string path values (dict or list). Wrap all `.get('path', ...)` accesses with `str()` to ensure string coercion.

## Required spec references

- specs/21_worker_contracts.md: W7 ContentReviewer worker contract
- abstract-hugging-kite.md:484-556: Scoring rubric

## Scope

### In scope

- `scoring.py`: 3 locations where `path` is extracted from issue location without `str()` wrapping
- `worker.py`: 2 locations where `path` is extracted from issue location without `str()` wrapping
- Unit tests for malformed location handling

### Out of scope

- Changes to check modules that produce the malformed locations
- LLM score verification (TC-2339)
- Post-LLM re-scoring (TC-2341)

## Inputs

- Issue dicts from check modules with potentially non-string `location.path` values

## Outputs

- Crash-free scoring regardless of path type in issue locations
- Unit tests verifying dict and list path values do not crash

## Allowed paths

- `src/launch/workers/w7_content_reviewer/scoring.py`
- `src/launch/workers/w7_content_reviewer/worker.py`
- `tests/unit/workers/test_content_reviewer_scoring.py`
- `plans/taskcards/TC-2338.md`

## Implementation steps

1. In `scoring.py` line 63: wrap `issue.get('location', {}).get('path', 'unknown')` with `str()`
2. In `scoring.py` line 149: wrap `issue.get("location", {}).get("path", "unknown")` with `str()`
3. In `scoring.py` line 261: wrap `loc.get('path', 'unknown')` with `str()`
4. In `worker.py` line 276: wrap sort key path access with `str()`
5. In `worker.py` line 298: wrap page path extraction with `str()`
6. Add 3 unit tests for malformed location handling

## Failure modes

1. **Regression in existing scoring**: Detection: existing tests fail. Mitigation: run full test suite before and after changes. Resolution: revert if tests break.
2. **str() produces unhelpful string for dict/list paths**: Detection: scoring groups pages incorrectly. Mitigation: str() of dict/list produces deterministic repr, which is sufficient for grouping. Resolution: acceptable trade-off vs crash.
3. **Missing a path extraction site**: Detection: crash persists in production. Mitigation: grep for all `.get('path'` patterns in scoring.py and worker.py. Resolution: add str() to any missed sites.
