## Objective

Register a dedicated `feature_blog` generator for per-feature blog posts with friendly tone, "you/your" voice, and quick code examples.

## Required spec references

- specs/07_section_templates.md: Page role definitions

## Scope

- Create feature_blog.txt prompt
- Add generate_feature_blog_content() and fallback
- Register (no aliases)

## Inputs

- product_facts with claims
- snippet_catalog
- page with title, purpose

## Outputs

- Markdown with: Introduction, Key Highlights, Quick Example, Next Steps
- Friendly, developer-focused tone

## Allowed Paths

- `src/launch/workers/w5_section_writer/generators/content_generators.py`
- `src/launch/workers/w5_section_writer/generators/__init__.py`
- `src/launch/workers/w5_section_writer/prompts/feature_blog.txt`
- `tests/unit/workers/test_tc_440_section_writer.py`
- `plans/taskcards/TC-2347.md`

## Implementation Steps

1. Create feature_blog.txt prompt with friendly tone rules
2. Add generate_feature_blog_content() function
3. Add _build_deterministic_feature_blog() fallback
4. Register in __init__.py
5. Add unit tests

## Failure Modes

1. Too formal tone -> prompt emphasizes "you/your" voice
2. No features to highlight -> fallback uses generic highlights
3. No snippet -> fallback generates placeholder code
