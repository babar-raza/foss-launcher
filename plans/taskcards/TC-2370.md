## Objective

Upgrade Gate 15 (API Hallucination Detection) to cross-reference method signatures
against `code_analysis.json` in addition to the existing class-name check. When
a backtick-quoted expression like `` `ClassName.method()` `` references a class that
IS known but a method that is NOT in that class's method list, emit a warn-level
issue (G15-002: GATE15_UNKNOWN_METHOD).

**Root cause (RCA Part 4-E)**: Gate 15 currently only checks the top-level class name
(`ClassName`). If the LLM fabricates `ClassName.nonexistent_method()`, it passes Gate 15
because `ClassName` is real. Method-level validation closes this gap.

## Scope

### In scope

- Extend `execute_gate()` in `gate_15_api_hallucination.py`:
  - When loading `code_analysis.json`, extract `class_methods: Dict[str, Set[str]]`
    from each class's `methods` list (handles both string and dict method entries)
  - For each matched `full_ref` containing `.` where the class name IS in `known_symbols`:
    - Extract member name (strip call-parentheses and args)
    - If class is in `class_methods` AND member not in that set → G15-002 warn
- Add 4 unit tests in new file `tests/unit/workers/test_gate_15_api_hallucination.py`
- Gate still always passes (warn-only, no blockers)

### Out of scope

- Changing Gate 15 severity to error/blocker
- Checking chained methods (e.g. `a.b.c()`) beyond the first `.`
- Modifying other gates

## Implementation steps

1. In `execute_gate()`, after the existing `code_analysis.json` loop, add:
   ```python
   class_methods: Dict[str, Set[str]] = {}
   for cls in code_analysis.get("classes", []):
       cls_data = cls if isinstance(cls, dict) else {"name": cls}
       cls_name = cls_data.get("name", "")
       methods = cls_data.get("methods", [])
       if cls_name:
           class_methods[cls_name] = {
               m if isinstance(m, str) else m.get("name", "")
               for m in methods
           } - {""}
   ```

2. In the per-match loop, after the existing unknown-symbol check, add:
   ```python
   # TC-2370: method signature check
   if "." in full_ref and symbol in known_symbols:
       member = full_ref.split(".")[1].split("(")[0]
       if symbol in class_methods and member and member not in class_methods[symbol]:
           file_issues.append({
               "issue_id": f"gate15_unknown_method_{md_file.stem}_{line_num}_{symbol}_{member}",
               "gate": "gate_15_api_hallucination",
               "severity": "warn",
               "message": f"Unknown method `{full_ref}` on class `{symbol}`",
               "error_code": "GATE15_UNKNOWN_METHOD",
               "location": {"path": str(md_file), "line": line_num},
               "status": "OPEN",
           })
   ```

3. Add 4 tests in `tests/unit/workers/test_gate_15_api_hallucination.py`:
   - `test_unknown_method_on_known_class_warns`
   - `test_known_method_on_known_class_passes`
   - `test_dotted_no_methods_data_skips`
   - `test_single_symbol_no_dot_unchanged`

## Acceptance criteria

- All existing Gate 15 behaviour unchanged for top-level class checks
- `` `KnownClass.unknownMethod()` `` → G15-002 warn issued
- `` `KnownClass.realMethod()` `` → no issue
- When `class_methods` is empty (no methods in code_analysis) → no method check performed
- Gate still always passes (warnings only)
- 4 new tests pass
