## Objective

Reduce W7 ContentReviewer wall-clock time by ~2–4x through three targeted optimizations:

1. **Parallel dimension execution** — run all 4 check dimensions (Content Quality, Technical
   Accuracy, Usability, Semantic Accuracy) concurrently using `ThreadPoolExecutor`.
2. **Semantic accuracy caching** — reuse semantic issues across deterministic auto-fix re-checks
   (since deterministic fixes cannot alter API hallucination or relevance results). Only refresh
   after LLM regen.
3. **Parallel post-sanitization** — apply 22 per-file sanitizers concurrently across draft files.

W7 is the pipeline's 82-minute bottleneck. The primary culprit: semantic accuracy runs 3–4 times
(initial + after each fix pass + after LLM regen), each time spawning per-file LLM calls with a
30-second timeout.

### Step 2: Add `_run_checks_parallel()` helper (module-level, before `execute_content_reviewer`)

```python
def _run_checks_parallel(
    drafts_dir,
    product_facts,
    snippet_catalog,
    evidence_map,
    page_plan,
    llm_client,
    n_workers: int = 4,
    *,
    include_semantic: bool = True,
):
    """Run W7 check dimensions concurrently.

    Returns (all_issues, semantic_issues) where semantic_issues is the result
    of semantic_accuracy.check_all() — empty list when include_semantic=False.
    """
    dims = {
        "cq": (content_quality.check_all, {
            "drafts_dir": drafts_dir,
            "product_facts": product_facts,
            "page_plan": page_plan,
        }),
        "ta": (technical_accuracy.check_all, {
            "drafts_dir": drafts_dir,
            "product_facts": product_facts,
            "snippet_catalog": snippet_catalog,
            "evidence_map": evidence_map,
            "page_plan": page_plan,
        }),
        "us": (usability.check_all, {
            "drafts_dir": drafts_dir,
            "page_plan": page_plan,
            "product_facts": product_facts,
        }),
    }
    if include_semantic:
        dims["sa"] = (semantic_accuracy.check_all, {
            "drafts_dir": drafts_dir,
            "product_facts": product_facts,
            "llm_client": llm_client,
            "snippet_catalog": snippet_catalog,
        })

    all_issues: list = []
    semantic_issues: list = []
    effective = min(n_workers, len(dims)) if n_workers > 1 else 1

    if effective <= 1:
        for name, (fn, kwargs) in dims.items():
            result = list(fn(**kwargs))
            if name == "sa":
                semantic_issues = result
            all_issues.extend(result)
        return all_issues, semantic_issues

    with ThreadPoolExecutor(max_workers=effective, thread_name_prefix="w7_checks") as pool:
        futures = {pool.submit(fn, **kwargs): name for name, (fn, kwargs) in dims.items()}
        for fut in as_completed(futures):
            name = futures[fut]
            try:
                result = list(fut.result())
            except Exception as exc:
                logger.warning("[W7] Check dimension %s failed: %s", name, exc)
                result = []
            if name == "sa":
                semantic_issues = result
            all_issues.extend(result)

    return all_issues, semantic_issues
```

```python
def _sanitize_draft_file(draft_file: Path, family: str, platform: str) -> None:
    """Apply W7 post-sanitizers to one draft file in-place (TC-2403)."""
    from .._shared.content_sanitizer import (
        fix_single_backtick_code_blocks,
        fix_code_fences,
        fix_trailing_periods_in_code,
        fix_excess_backtick_fences,
        fix_nested_fences,
        collapse_duplicate_fence_openings,
        fence_bare_commands,
        fence_bare_code_lines,
        fix_bare_language_line,
        fix_prose_in_code_blocks,
        strip_visible_claim_markers,
        strip_orphan_claim_markers,
        strip_pipeline_comments,
        strip_emojis,
        strip_boilerplate_sentences,
        strip_llm_scaffolding,
        merge_adjacent_code_blocks,
        strip_double_periods,
        fix_collapsed_frontmatter,
        absolutize_links,
        close_unclosed_fences,
    )

    def _safe(fn, content, *args):
        try:
            return fn(content, *args)
        except Exception as exc:
            logger.warning("[W7] Post-sanitize %s failed for %s: %s", fn.__name__, draft_file.name, exc)
            return content

    try:
        text = draft_file.read_text(encoding="utf-8")
    except Exception:
        return

    sanitized = _safe(strip_llm_scaffolding, text)
    sanitized = _safe(fence_bare_commands, sanitized)
    sanitized = _safe(fix_bare_language_line, sanitized)
    sanitized = _safe(fence_bare_code_lines, sanitized)
    sanitized = _safe(fix_collapsed_frontmatter, sanitized)
    sanitized = _safe(close_unclosed_fences, sanitized)
    sanitized = _safe(fix_nested_fences, sanitized)
    sanitized = _safe(fix_single_backtick_code_blocks, sanitized)
    sanitized = _safe(fix_excess_backtick_fences, sanitized)
    sanitized = _safe(collapse_duplicate_fence_openings, sanitized)
    sanitized = _safe(fix_code_fences, sanitized)
    sanitized = _safe(fix_trailing_periods_in_code, sanitized)
    sanitized = _safe(fix_prose_in_code_blocks, sanitized)
    sanitized = _safe(merge_adjacent_code_blocks, sanitized)
    sanitized = _safe(strip_visible_claim_markers, sanitized)
    sanitized = _safe(strip_pipeline_comments, sanitized)
    sanitized = _safe(strip_orphan_claim_markers, sanitized)
    sanitized = _safe(strip_emojis, sanitized)
    sanitized = _safe(strip_boilerplate_sentences, sanitized)
    sanitized = _safe(strip_double_periods, sanitized)
    _section = "default"
    rel = str(draft_file).replace("\\", "/")
    for sec in ("docs", "reference", "kb", "blog", "products"):
        if f"{sec}.aspose.org" in rel:
            _section = sec
            break
    sanitized = _safe(absolutize_links, sanitized, _section, family, platform)
    if sanitized != text:
        draft_file.write_text(sanitized, encoding="utf-8")
```

### Step 5: Write tests (`test_parallel_review.py`)

Minimum 5 tests covering:
1. `_run_checks_parallel` with `include_semantic=True` calls semantic dimension
2. `_run_checks_parallel` with `include_semantic=False` does NOT call semantic

## Failure modes

1. **Thread exception from check dimension** — Detection: `fut.result()` raises. Resolution:
   `except Exception` logs warning, appends empty list; W7 continues with available issues.
   Link: `specs/08_content_reviewer.md` §Performance.

2. **Semantic cache stale after unexpected mutation** — Detection: LLM regen path always refreshes
   `_semantic_cache`; auto-fix paths only reuse it. If an auto-fix somehow corrupts semantic content
   (not expected), the final state is caught by the post-LLM re-check. Link: `specs/08_content_reviewer.md`.

3. **Post-sanitization file write conflict** — Detection: each `draft_file` is a unique path;
   no two threads write the same file. If write fails, exception logged per-file; other files
   continue unaffected. Link: `specs/21_worker_contracts.md` §write isolation.

4. **`n_workers > len(dims)`** — Detection: `effective = min(n_workers, len(dims))` caps the pool.
   No idle threads created. No crash or behavioral difference.

5. **`max_parallel_workers_w7` absent from run_config** — Detection: `run_config.get(..., 4)`
   returns default 4. Backward-compatible. Link: `specs/schemas/run_config.schema.json`.
