## Objective

Add per-role context builders to W5 `content_generators.py` so each specialized
generator receives the right claims and snippets for its page type, instead of all
generators using the generic `_build_enriched_claim_context()` + first-5-snippets
pattern. Uses `demo_snippet_ids` from TC-2368 to prioritize claim-linked snippets.

**Root cause (RCA H3, H1)**: All generators receive generic, unranked claim context
and random first-5 snippets from catalog. Each page type needs different context shape.

## Scope

### In scope

- Add 3 context builder functions to `content_generators.py`:
  - `build_tutorial_context(page, product_facts, snippet_catalog)` → dict
    - Orders claims: workflow/feature kinds first, other kinds after
    - Gets snippets: from demo_snippet_ids of ordered claims, fallback to first-5
  - `build_feature_showcase_context(page, product_facts, snippet_catalog, primary_claim, related_claims)` → dict
    - Gets snippets: from demo_snippet_ids of primary_claim, fallback to first-5
  - `build_api_reference_context(page, product_facts, snippet_catalog)` → dict
    - Orders claims: api/format kinds alphabetically by claim_text, others after
    - Gets snippets: from demo_snippet_ids of api claims, fallback to 'api'-tagged snippets
- Update `generate_tutorial_content()` to use `build_tutorial_context()` for
  the `enriched_context` and `snippet_text` variables (instead of generic call + first-5)
- Update `generate_feature_showcase_content()` to use `build_feature_showcase_context()`
  for `enriched_context` and `snippet_context` variables
- Add 4 unit tests in `tests/unit/workers/test_tc_440_section_writer.py`

### Out of scope

- Changing `generate_api_reference_content()` (complex existing logic, future work)
- Changing the LLM call or prompt templates
- Changing claim_ids assignment in W4
- Changing snippet_catalog schema

## Context Builder Signatures

Each builder returns a dict with keys:
- `claims: List[Dict]` — ordered claim list for this page type
- `snippets: List[Dict]` — relevant snippet dicts (max 5)
- `claim_context: str` — formatted string from `_build_enriched_claim_context()`
- `snippet_text: str` — formatted snippet code blocks for LLM prompt

## Implementation steps

1. Add `build_tutorial_context()`:
   ```python
   def build_tutorial_context(page, product_facts, snippet_catalog):
       claim_ids = page.get("claim_ids", [])
       all_claims = product_facts.get("claims", [])
       claim_id_set = set(claim_ids)
       claims = [c for c in all_claims if c.get("claim_id") in claim_id_set]
       # Order: workflow/feature first
       wf = [c for c in claims if c.get("claim_kind") in ("workflow", "feature")]
       other = [c for c in claims if c.get("claim_kind") not in ("workflow", "feature")]
       ordered = (wf + other)[:10]
       # Collect demo snippet IDs from ordered claims
       demo_ids, seen = [], set()
       for c in ordered:
           for sid in c.get("demo_snippet_ids", []):
               if sid not in seen:
                   demo_ids.append(sid); seen.add(sid)
       all_snippets = snippet_catalog.get("snippets", [])
       smap = {s.get("snippet_id", ""): s for s in all_snippets}
       snippets = [smap[sid] for sid in demo_ids if sid in smap] or all_snippets[:5]
       snippet_text = "\n\n".join(
           f"```{s.get('language','python')}\n{s.get('code','')}\n```"
           for s in snippets[:5]
       )
       return {"claims": ordered, "snippets": snippets[:5],
               "claim_context": _build_enriched_claim_context(ordered, product_facts),
               "snippet_text": snippet_text}
   ```

2. Add `build_feature_showcase_context()`:

   ```python
   def build_feature_showcase_context(page, product_facts, snippet_catalog,
                                       primary_claim, related_claims):
       all_feature_claims = [primary_claim] + related_claims
       demo_ids, seen = [], set()
       for c in all_feature_claims:
           for sid in c.get("demo_snippet_ids", []):
               if sid not in seen:
                   demo_ids.append(sid); seen.add(sid)
       all_snippets = snippet_catalog.get("snippets", [])
       smap = {s.get("snippet_id", ""): s for s in all_snippets}
       snippets = [smap[sid] for sid in demo_ids if sid in smap] or all_snippets[:5]
       snippet_text = "\n\n".join(
           (f"# {s.get('description','')}\n{s.get('code','')}" if s.get('description')
            else s.get('code', ''))
           for s in snippets[:5]
       )
       return {"claims": all_feature_claims, "snippets": snippets[:5],
               "claim_context": _build_enriched_claim_context(all_feature_claims, product_facts),
               "snippet_text": snippet_text or "No code examples available."}
   ```

3. Add `build_api_reference_context()`:
   ```python
   def build_api_reference_context(page, product_facts, snippet_catalog):
       claim_ids = page.get("claim_ids", page.get("required_claim_ids", []))
       all_claims = product_facts.get("claims", [])
       claim_id_set = set(claim_ids)
       claims = [c for c in all_claims if c.get("claim_id") in claim_id_set]
       api = sorted([c for c in claims if c.get("claim_kind") in ("api","format")],
                    key=lambda c: c.get("claim_text","").lower())
       other = [c for c in claims if c.get("claim_kind") not in ("api","format")]
       ordered = (api + other)[:20]
       demo_ids, seen = [], set()
       for c in api:
           for sid in c.get("demo_snippet_ids", []):
               if sid not in seen:
                   demo_ids.append(sid); seen.add(sid)
       all_snippets = snippet_catalog.get("snippets", [])
       smap = {s.get("snippet_id", ""): s for s in all_snippets}
       snippets = [smap[sid] for sid in demo_ids if sid in smap]
       if not snippets:
           snippets = [s for s in all_snippets
                       if any(t in s.get("tags",[]) for t in ["api","reference"])][:5] \
                      or all_snippets[:5]
       snippet_text = "\n\n".join(
           f"```{s.get('language','python')}\n{s.get('code','')}\n```"
           for s in snippets[:5]
       )
       return {"claims": ordered, "snippets": snippets[:5],
               "claim_context": _build_enriched_claim_context(ordered, product_facts),
               "snippet_text": snippet_text}
   ```
