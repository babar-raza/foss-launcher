## Objective

When W7 ContentReviewer returns `overall_status: REJECT`, rather than continuing
to W6 with structurally broken content, the orchestrator routes to a new
`redraft_pages` node. This node marks only the failing pages as `page_status: "new"`
in `page_plan.json` (preserving passing pages), then routes back to W5 SectionWriter.
W5 re-drafts only the failing pages (via its existing incremental preserved-page
mechanism) and W7 runs again.

Default `redraft_enabled=false` means existing pipelines are completely unaffected.

### Step 3: Implement `decide_after_review()` in `graph.py`

```python
def decide_after_review(state: OrchestratorState) -> str:
    """Route after W7 ContentReviewer.

    Returns "redraft" if redraft_enabled, overall_status==REJECT,
    pages_failed > 0, and attempts not exhausted. Otherwise "continue".

    Spec: specs/09_validation_gates.md §"W7 → W5 Selective Re-Draft Routing"
    """
    rc = state["run_config"]
    if not rc.get("redraft_enabled", False):
        return "continue"
    run_dir = Path(state["run_dir"])
    review_report_path = run_dir / "artifacts" / "review_report.json"
    if not review_report_path.exists():
        return "continue"
    try:
        review_report = json.loads(review_report_path.read_text(encoding="utf-8"))
    except Exception:
        return "continue"
    if review_report.get("overall_status") != "REJECT":
        return "continue"
    if review_report.get("pages_failed", 0) == 0:
        return "continue"
    max_attempts = rc.get("max_redraft_attempts", 1)
    if state.get("redraft_attempts", 0) >= max_attempts:
        logger.warning(
            f"[Orchestrator] W7 REJECT but redraft_attempts exhausted "
            f"({state.get('redraft_attempts', 0)}/{max_attempts}), continuing to W6"
        )
        return "continue"
    return "redraft"
```

### Step 4: Implement `redraft_pages_node()` in `graph.py`

```python
def redraft_pages_node(state: OrchestratorState) -> dict:
    """Mark W7-failing pages as 'new' in page_plan.json; preserve passing pages.

    Routes back to draft_sections (W5), which skips preserved pages.
    Spec: specs/09_validation_gates.md §"W7 → W5 Selective Re-Draft Routing"
    """
    run_dir = Path(state["run_dir"])

    # 1. Collect failing page draft paths from review_report.json
    review_report_path = run_dir / "artifacts" / "review_report.json"
    review_report = json.loads(review_report_path.read_text(encoding="utf-8"))
    failing_paths = set()
    for issue in review_report.get("issues", []):
        loc = issue.get("location", {})
        path = loc.get("path", "")
        if path:
            failing_paths.add(path)

    # 2. Load page_plan.json
    page_plan_path = run_dir / "artifacts" / "page_plan.json"
    page_plan = json.loads(page_plan_path.read_text(encoding="utf-8"))

    # 3. Mark pages: failing → "new", others → "preserved"
    redraft_count = 0
    for page in page_plan.get("pages", []):
        draft_rel = page.get("draft_path", "")
        # Normalize to forward slashes for cross-platform comparison
        draft_rel_normalized = draft_rel.replace("\\", "/")
        is_failing = any(
            fp.replace("\\", "/") in draft_rel_normalized or
            draft_rel_normalized in fp.replace("\\", "/")
            for fp in failing_paths
        )
        if is_failing:
            page["page_status"] = "new"
            redraft_count += 1
        else:
            page["page_status"] = "preserved"

    logger.info(
        f"[Orchestrator] Re-draft: {redraft_count}/{len(page_plan.get('pages', []))} "
        f"pages marked for re-generation (attempt "
        f"{state.get('redraft_attempts', 0) + 1})"
    )

    # 4. Write updated page_plan.json atomically
    tmp_path = page_plan_path.with_suffix(".tmp")
    tmp_path.write_text(json.dumps(page_plan, indent=2), encoding="utf-8")
    tmp_path.replace(page_plan_path)

    # 5. Emit RUN_STATE_REDRAFTING event (use existing emit_event pattern)
    # (Orchestrator emits state change event via run_loop mechanism)

    return {"redraft_attempts": state.get("redraft_attempts", 0) + 1}
```

## Failure modes

1. **`review_report.json` missing when `decide_after_review` runs** — Detection: `not exists()`.
   Resolution: return "continue" (fall through to W6). No crash.
   Spec/gate: specs/09_validation_gates.md §routing decision logic.

2. **`page_plan.json` write fails mid-update** — Detection: exception during atomic write.
   Resolution: tmp file used; original untouched if `replace()` fails. Pipeline fails with
   explicit error. Spec/gate: specs/21_worker_contracts.md atomic write requirement.

3. **Infinite redraft loop** — Detection: `redraft_attempts >= max_redraft_attempts`.
   Resolution: route "continue" to W6 with warning logged. Loop guard mandatory.
   Spec/gate: specs/09_validation_gates.md §"Loop Guard".
