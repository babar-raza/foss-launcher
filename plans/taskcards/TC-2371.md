## Objective

Add Gate 18 (Code-Prose Balance) to W9 Validator. For page roles that must include
code examples (tutorial, feature_showcase, comprehensive_guide, api_reference),
verify that there is at least 1 code block per 400 words of body prose. Pages that
fail get a warn-level G18-001 issue.

**Root cause (RCA Part 4-E)**: Gates currently don't check whether code-heavy page
types actually contain code. A tutorial page can pass all gates with zero code examples.

## Required spec references

- `specs/09_validation_gates.md`
- `C:\Users\prora\.claude\plans\reactive-weaving-clock.md` §"Gate 18 (new): Code-prose balance"

## Scope

### In scope

- New file `gate_18_code_prose_balance.py` with `run_gate_18(pages)`:
  - Roles checked: `tutorial`, `feature_showcase`, `comprehensive_guide`, `api_reference`
  - Count actual code blocks (``` pairs) in body
  - Count words in body after stripping frontmatter and code blocks
  - Required blocks = max(1, word_count // 400)
  - If actual < required → G18-001 warn
- Register in `gates/__init__.py`
- Invoke after Gate 16 in `worker.py` (reusing `pages_g16`)
- 4 unit tests in `tests/unit/workers/test_gate_18_code_prose_balance.py`
- Gate passes (warn only — no blocker/error)

### Out of scope

- Changing severity to error/blocker
- Applying check to faq, toc, landing, blog, workflow_page roles
- Modifying existing gates

## Implementation steps

1. Create `gate_18_code_prose_balance.py` with:
   - `_strip_frontmatter(content)` helper
   - `_strip_code_blocks(content)` helper (blanks out code block lines)
   - `_slug(path)` helper
   - `run_gate_18(pages)` main function

2. Add to `gates/__init__.py` `__all__` list: `"gate_18_code_prose_balance"`

3. In `worker.py` after Gate 16 block, add Gate 18 invocation reusing `pages_g16`

4. Add 4 tests

## Acceptance criteria

- Tutorial with 500 words and 0 code blocks → G18-001 warn
- Tutorial with 500 words and 2 code blocks → no issue
- FAQ page (not in CODE_REQUIRED_ROLES) → no issue regardless of content
- Short page (<400 words) → still requires ≥1 code block
- Gate always passes (no blockers/errors)
- 4 new tests pass
