## Objective

Register a dedicated `workflow_page` generator in W5 GeneratorRegistry so that pages with `page_role=workflow_page` get a specialized prompt instead of falling to the weak generic prompt. Fixes 6 pages that currently produce low-quality content.

## Required spec references

- specs/07_section_templates.md: Page role definitions
- specs/08_section_writer.md: Generator interface contract

## Scope

- Create prompt file `src/launch/workers/w5_section_writer/prompts/workflow_page.txt`
- Add `generate_workflow_page_content()` and `_build_deterministic_workflow_page()` to content_generators.py
- Register with aliases=["workflow"] in __init__.py
- Add unit tests

## Inputs

- product_facts with claims
- snippet_catalog with code examples
- page dict with title, purpose, content_strategy

## Outputs

- Markdown content with: Overview, What You'll Learn, Prerequisites, Steps, Complete Example, See Also
- Claim markers injected as HTML comments

## Implementation Steps

1. Create workflow_page.txt prompt with strict structure rules
2. Add generate_workflow_page_content() following FAQ generator pattern
3. Add _build_deterministic_workflow_page() fallback
4. Register in __init__.py with aliases=["workflow"]
5. Add unit tests for deterministic output

## Failure Modes

1. Prompt template has unescaped braces -> test prompt.format() with all fields
2. LLM fallback not triggered -> verify word count threshold check
3. Missing claim markers -> verify _inject_claim_markers() called
