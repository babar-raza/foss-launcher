## Objective

Add an automated E2E regression test that fails if required sections (products, blog, kb) ever end up with 0 pages after W2 topic discovery + W4 planning. Tests run without real LLM calls (offline/deterministic mode) and validate the full W2→W4 contract.

## Required spec references

- specs/21_worker_contracts.md (W2/W4 I/O contracts)
- specs/43_resumable_pipeline.md (Offline mode behavior)

- New test file `test_mandatory_sections_e2e.py` with 7 test methods

## Failure modes

### FM-1: RunLayout or atomic_write_json import path changed
- **Detection signal**: ImportError at test collection time
- **Resolution**: Check current import paths in src/launch/io/ and update
- **Gate link**: Test collection phase

### FM-2: execute_ia_planner signature changed
- **Detection signal**: TypeError on unexpected keyword arguments
- **Resolution**: Read W4 worker.py entry point and align test parameters
- **Gate link**: test_w4_produces_pages_for_all_required_sections

### FM-3: Synthetic claims insufficient for W4 page generation
- **Detection signal**: W4 produces 0 pages for a section despite claims being present
- **Resolution**: Add more diverse claim_kinds to SYNTHETIC_CLAIMS fixture; ensure feature, workflow, performance, api_reference kinds present
- **Gate link**: test_w4_produces_pages_for_all_required_sections
