## Objective

Register a dedicated `landing` generator for product landing pages. NO code examples on landing pages. Value proposition + feature highlights + CTA.

## Required spec references

- specs/07_section_templates.md: Page role definitions

## Scope

- Create landing.txt prompt
- Add generate_landing_content() and _build_deterministic_landing()
- Register with aliases=["landing_page", "product_landing"]

## Inputs

- product_facts with claims and product_name
- page dict with title, purpose

## Outputs

- Markdown content with: Value prop, Key Features, Getting Started CTA
- No code examples

## Allowed Paths

- `src/launch/workers/w5_section_writer/generators/content_generators.py`
- `src/launch/workers/w5_section_writer/generators/__init__.py`
- `src/launch/workers/w5_section_writer/prompts/landing.txt`
- `tests/unit/workers/test_tc_440_section_writer.py`
- `plans/taskcards/TC-2331.md`

## Implementation Steps

1. Create landing.txt prompt
2. Add generate_landing_content() function
3. Add _build_deterministic_landing() fallback
4. Register in __init__.py
5. Add unit tests

## Failure Modes

1. Code examples leak into landing page -> prompt explicitly forbids code
2. Missing value proposition -> deterministic fallback includes one
3. No CTA -> deterministic fallback includes navigation links

## Review Checklist

- [ ] No code fences in landing output
- [ ] Value proposition present

- [ ] Registry has all aliases
- [ ] Unit tests pass
