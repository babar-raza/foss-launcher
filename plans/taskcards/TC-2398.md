## Failure modes

1. **Incomplete alias table** — spec omits a worker alias, causing TC-2399 to implement
   an incomplete `RESUME_NODE_MAP`. Detection: review spec table against 11-worker pipeline.
   Resolution: ensure all W1–W11 aliases and full node names are listed. Gate: TC-2399 tests.

2. **Wrong pre-execution run_state** — spec maps a node to the wrong `run_state` value,
   causing initial_state in execute_run_from_node() to be incorrect, leading to state machine
   violations. Detection: cross-reference with `src/launch/models/state.py` constants.
   Resolution: validate each state against the state transition diagram in `specs/11_state_and_events.md`.

3. **Missing artifact in table** — spec omits a required input artifact for a worker entry
   point, causing silent failures downstream when an artifact is absent. Detection: cross-
   reference with worker_invoker.py inputs for each worker. Resolution: add missing artifacts
   before TC-2399 implementation begins.
