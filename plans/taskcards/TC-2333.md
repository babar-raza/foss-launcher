## Objective

Fix comprehensive guide generator to use `_get_display_text(claim)` instead of raw `claim.get('claim_text', '')`. The helper prefers enriched_text (marketing-ready) over claim_text (raw extraction).

## Required spec references

- specs/08_section_writer.md: Content quality requirements

## Scope

- Replace raw claim_text access in no-workflows fallback (Key Capabilities section)
- Replace raw claim_text access in Limitations sections (both with-workflows and no-workflows branches)

## Inputs

- Claims with enriched_text and claim_text fields

## Outputs

- Content using enriched_text when available

## Allowed Paths

- `src/launch/workers/w5_section_writer/generators/content_generators.py`
- `tests/unit/workers/test_tc_440_section_writer.py`

## Implementation Steps

1. Find all `claim.get('claim_text', '')` in comprehensive guide function
2. Replace with `_get_display_text(claim)`
3. Verify no other raw claim_text access in the function
4. Add test verifying enriched_text is preferred
