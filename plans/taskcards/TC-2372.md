## Objective

Add Gate 19 (Cross-Page Redundancy) to W9 Validator. Pages in the same section
(parent directory) that share >60% of significant word content (Jaccard similarity,
after stripping frontmatter, code blocks, and stopwords) are flagged with a
warn-level G19-001 issue. This catches the common problem of LLM paraphrasing
one page's content into another.

**Root cause (RCA Part 4-E)**: Manual review catches duplicate/near-duplicate pages.
No automated gate currently detects this. A pipeline run can produce 3 pages in the
same section that all say the same thing in slightly different words.

## Scope

### In scope

- New file `gate_19_redundancy.py` with `run_gate_19(pages)`:
  - Group pages by `Path(page["path"]).parent`
  - For each section with ≥2 pages: pairwise Jaccard on significant word sets
  - Similarity > 0.6 → G19-001 warn
  - `_tokenize(text)`: lowercase, ≥3-char words, stopword removal
- Register in `gates/__init__.py`
- Invoke after Gate 18 in `worker.py` (reusing `pages_g16`)
- 4 unit tests in `tests/unit/workers/test_gate_19_redundancy.py`
- Gate passes (warn only)

### Out of scope

- Comparing pages across sections
- Detecting near-duplicate headings only
- Modifying existing gates

## Stopword list

```python
STOPWORDS = frozenset({
    "the", "and", "or", "of", "a", "an", "in", "is", "to", "for",
    "with", "that", "this", "are", "be", "have", "from", "by", "at",
    "as", "on", "it", "its", "not", "but", "can", "you", "we",
    "our", "your", "will", "all", "use", "used", "using", "how",
})
```

## Acceptance criteria

- Two pages in same dir with >60% Jaccard word overlap → G19-001 warn
- Two pages in same dir with <60% overlap → no issue
- Two pages in different dirs with >60% overlap → no issue
- One page per dir → no issue
- Gate always passes (warn only, no blocker/error)
- 4 new tests pass
