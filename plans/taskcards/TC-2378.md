## Objective

Replace 14 `in_fence = not in_fence` boolean toggle sites in `content_sanitizer.py` with a
robust integer counter (`_FenceState` class) that correctly handles nested and unmatched fences.

**Note**: TC-2354 ("Sanitizer instrumentation and audit") is In-Progress and may already touch
`content_sanitizer.py`. Check its `allowed_paths` before modifying — if TC-2354 includes fence
parser changes, coordinate. Otherwise, proceed independently since TC-2378 is limited to the
toggle→counter replacement.

## Background

Boolean toggle `in_fence = not in_fence` is incorrect when a document has an odd number of fence
markers (e.g., an unclosed code block). The toggle causes the state to invert incorrectly, treating
subsequent prose as code and vice versa. This causes sanitizer functions to skip or corrupt content.

The fix: use an integer depth counter that clamps to 0 (never negative), making it idempotent and
resilient to unmatched fences.

## Governance (spec first)

Before any code changes, amend `specs/21_worker_contracts.md` to add:

### Shared.1 Fence Parser Contract
> All sanitizer functions MUST track fence depth with an integer counter (not a boolean toggle).
> Counter increments when a line starts with ` ``` ` or `~~~` (after strip) and depth is 0.
> Counter decrements when a line starts with ` ``` ` or `~~~` and depth is > 0.
> Depth clamps to 0 (never negative). `in_fence` is derived as `depth > 0`.
> Idempotency: `f(f(x)) == f(x)` is a hard contract on all sanitizer functions.

## Implementation

### Step 1: Add `_FenceState` class to `content_sanitizer.py`

Add near the top of the file (after imports, before first function):

```python
class _FenceState:
    """Counter-based fence depth tracker (replaces boolean toggle).

    Idempotent: depth clamps to 0 on unmatched closing fences.
    """
    def __init__(self):
        self.depth = 0

    def process_line(self, line: str) -> None:
        stripped = line.strip()
        if stripped.startswith("```") or stripped.startswith("~~~"):
            if self.depth == 0:
                self.depth = 1
            else:
                self.depth = max(0, self.depth - 1)

    @property
    def in_fence(self) -> bool:
        return self.depth > 0
```

### Step 3: Replace each toggle pattern

For each function containing `in_fence = not in_fence`:

**Before** (existing pattern):
```python
in_fence = False
for line in lines:
    if line.strip().startswith("```"):
        in_fence = not in_fence
    if in_fence:
        result.append(line)
        continue
    # ... processing logic
```

**After** (counter pattern):
```python
fence = _FenceState()
for line in lines:
    fence.process_line(line)
    if fence.in_fence:
        result.append(line)
        continue
    # ... processing logic
```

**IMPORTANT**: Read each function carefully before replacing. Some functions may use `in_fence`
in multiple places (e.g., tracking both entry and body). Replace ALL usages within each function.
