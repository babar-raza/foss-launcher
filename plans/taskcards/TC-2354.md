## Objective

Instrument all ~43 sanitizer transforms in `run_pipeline()` to track which ones
actually fire (change content) per page. Produce `sanitizer_metrics.json` after
each W5 run. Use data to identify transforms that no longer fire after Phases 1-4
(multi-pass, citation excerpts, sufficiency check, acceptance criteria).

## Required spec references

- specs/08_section_writer.md: W5 sanitizer contract
- specs/21_worker_contracts.md: Pipeline post-processing

## Scope

- Add `SanitizerMetrics` class to `content_sanitizer.py`
- Wrap each transform in `run_pipeline()` with fire tracking
- Expose `get_metrics()` and `reset_metrics()` functions
- Write `sanitizer_metrics.json` to artifacts after W5 completes
- Annotate zero-fire transforms as removal candidates
- Add unit tests for metrics tracking

## Inputs

- Content strings passed through `run_pipeline()`
- `SanitizerContext` with page metadata

## Outputs

- `sanitizer_metrics.json` in run artifacts:
  ```json
  {
    "transform_fire_counts": {"strip_emojis": 3, "fix_code_fences": 12, ...},
    "total_pages": 15,
    "transforms_that_never_fired": ["strip_ci_badges", ...]
  }
  ```

## Allowed Paths

- `src/launch/workers/_shared/content_sanitizer.py`
- `src/launch/workers/w5_section_writer/worker.py`
- `tests/unit/workers/test_content_sanitizer.py`

## Acceptance Criteria

- [ ] `SanitizerMetrics` tracks per-transform fire counts
- [ ] `run_pipeline()` uses tracked wrappers for all transforms
- [ ] `get_metrics()` returns current counts; `reset_metrics()` clears them
- [ ] W5 worker writes `sanitizer_metrics.json` to artifacts
- [ ] Zero-fire transforms annotated with removal candidate comments
- [ ] All unit tests pass
