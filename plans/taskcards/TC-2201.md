## Implementation steps

### R17-010: Dynamic blog slug
1. Add `_slugify()` helper in W4 (if not exists): convert product name to URL-safe slug
2. Update blog page creation (line ~2001):
   - Before: `"slug": "announcement"`
   - After: `blog_slug = _slugify(f"introducing-{product_name}")`
3. Update title: `f"Introducing {product_name} for Python — Open-Source {family} Processing"`
4. Add `_build_page_description()` call for blog description

### R17-011: skip_sections support
1. Add `skip_sections` to [run_config.schema.json](../../specs/schemas/run_config.schema.json):
   ```json
   "skip_sections": {
     "type": "array",
     "items": {"enum": ["products", "docs", "reference", "kb", "blog"]},
     "default": [],
     "description": "Sections to skip during page planning (TC-2201)"
   }
   ```
2. In W4 `execute_ia_planner()` line ~3500, add skip logic:
   ```python
   skip_sections = run_config.get("skip_sections", [])
   for section_name, subdomain in sections_list:
       if section_name in skip_sections:
           continue
   ```
3. Update both pilot configs: `skip_sections: ["products"]`

### R17-007: Claim-density expansion
1. In `plan_pages_for_section()` after base docs pages created (line ~1788):
   ```python
   # TC-2201 R17-007: Add topic cluster pages for high-claim repos
   n_claims = len(claims)
   if section == "docs" and n_claims > 200:
       covered_ids = set()
       for p in pages:
           covered_ids.update(p.get("required_claim_ids", []))

       uncovered_groups = {}
       for group_name, group_ids in claim_groups_dict.items():
           uncovered = [cid for cid in group_ids if cid not in covered_ids]
           if len(uncovered) >= 10:
               uncovered_groups[group_name] = uncovered

       for group_name, group_ids in sorted(uncovered_groups.items(), key=lambda x: -len(x[1]))[:5]:
           slug = _slugify(group_name)
           role = assign_page_role("docs", slug)
           strategy = build_content_strategy(role, "docs", workflows)
           pages.append({
               "section": "docs",
               "slug": slug,
               "output_path": compute_output_path("docs", slug, product_slug, platform=platform),
               "url_path": compute_url_path("docs", slug, product_slug, platform=platform),
               "title": _build_page_title(slug, "docs", product_name, platform),
               "description": _build_page_description(slug, "docs", product_name, platform, f"Guide for {group_name}"),
               "purpose": f"Detailed guide for {group_name.replace('_', ' ')}",
               "template_variant": launch_tier,
               "required_headings": ["Overview", "Usage", "Examples"],
               "required_claim_ids": sorted(group_ids)[:15],
               "required_snippet_tags": [],
               "cross_links": [],
               "seo_keywords": [product_slug, group_name.replace("_", " ")],
               "forbidden_topics": strategy.get("forbidden_topics", []),
               "page_role": role,
               "content_strategy": strategy,
           })
   ```

2. Add ~30 tests in `test_tc_430_ia_planner.py`:
   - Blog slug derived from product name
   - skip_sections filters out specified sections
   - High-claim repo (>200) gets extra docs pages
   - Low-claim repo (<200) gets base docs pages only
   - Claim group coverage tracking

3. Run full test suite

4. Document evidence

## Failure modes
### FM1: Schema validation fails
Detection signal: Pilot configs fail to load due to schema mismatch.
Resolution steps: Ensure `skip_sections` is optional (not required) and has correct enum values.
Spec/Gate link: specs/09_validation_gates.md (Gate 1: Config validation)

### FM2: Claim expansion creates duplicate pages
Detection signal: Multiple pages with same slug or overlapping content.
Resolution steps: Check covered_ids tracking and slug uniqueness.
Spec/Gate link: specs/21_worker_contracts.md (W4 page deduplication)

### FM3: Blog slug collision
Detection signal: Multiple products generate same blog slug.
Resolution steps: Include product family or unique identifier in slug pattern.
Spec/Gate link: specs/32_platform_aware_layout.md (URL path uniqueness)
