## Objective

Implement the `launch resume` command per `specs/43_resumable_pipeline.md`. Enables a
developer to re-enter the 11-worker pipeline at any specified worker, reusing artifacts
already produced by a prior run, without re-running earlier workers.

## Implementation steps

### Step 1 — `src/launch/orchestrator/graph.py`
Change signature:
```python
def build_orchestrator_graph(start_node: str = "clone_inputs") -> StateGraph:
```
Replace `graph.set_entry_point("clone_inputs")` with `graph.set_entry_point(start_node)`.
No other changes. Default preserves full backward compatibility.

### Step 2 — `src/launch/orchestrator/run_loop.py`

Add module-level constant (avoids shared-library violation):
```python
_EVENT_RUN_RESUMED = "RUN_RESUMED"
```

Add `RESUME_NODE_MAP` dict mapping all 22 aliases (11 short + 11 full node names) to
`(graph_node: str, pre_run_state: str, required_paths: List[str])` tuples per the spec table.

Add `_validate_resume_artifacts(run_dir: Path, required_paths: List[str]) -> None`:
- Checks each path exists (file or directory as appropriate)
- Raises `ValueError` listing ALL missing paths (not just the first)

Add `execute_run_from_node(run_id, run_dir, run_config, from_worker) -> RunResult`:
1. Resolve `from_worker` via `RESUME_NODE_MAP` — `ValueError` if unknown
2. Call `_validate_resume_artifacts(run_dir, required_paths)` — `ValueError` if missing
3. Load `snapshot` from `run_dir/snapshot.json` (may not exist for partial runs; use empty dict)
4. Initialize trace context (generate_trace_id / generate_span_id)
5. Emit `_EVENT_RUN_RESUMED` event to `events.ndjson` (append, same Event model as execute_run)
6. Build graph: `graph = build_orchestrator_graph(start_node=node_name)`, compile
7. Build `initial_state` identical to `execute_run()` except `run_state = pre_run_state`
8. Stream graph and emit state-change events exactly as `execute_run()` does
9. Return `RunResult` with final state and exit code

### Step 3 — `src/launch/cli/main.py`

Add new Typer command:
```python
@app.command()
def resume(
    run_dir: Path = typer.Option(..., "--run-dir", exists=True, file_okay=False),
    from_worker: str = typer.Option(..., "--from-worker"),
    verbose: bool = typer.Option(False, "--verbose", "-v"),
) -> None:
    """Resume a run from a specific worker, reusing prior artifacts."""
```

Steps:
1. Validate `run_dir` is under `_runs_dir()` via `validate_run_dir_under_runs()`
2. Load `run_config` from `run_dir / "run_config.yaml"` (yaml.safe_load); exit 1 if missing
3. `run_id = run_dir.name`
4. Validate `from_worker` in `RESUME_NODE_MAP` — exit 1 with alias list if unknown
5. Print summary: "Resuming <run_id> from <from_worker> (<node_name>), skipping W1..W(N-1)"
6. Call `execute_run_from_node(run_id, run_dir, run_config, from_worker)`
7. Print final state and exit with result.exit_code

### Step 4 — `scripts/run_pilot.py`

Add argument:
```python
parser.add_argument("--from-worker", default=None,
    help="Resume from specific worker using the most recent run for this pilot. "
         "E.g. --from-worker W5")
```

When `--from-worker` is set:
1. Read `runs/manifest.jsonl` lines; filter by `pilot == args.pilot`; take the last entry
2. Extract `output_dir` from that entry
3. Validate the directory exists; exit with error if not found
4. Build command: `[python, "-m", "launch", "resume", "--run-dir", output_dir, "--from-worker", args.from_worker]`
5. Run via subprocess, propagating exit code

### Step 5 — `tests/unit/orchestrator/test_resume_from_node.py`

Six tests (see §Test plan).

## Test plan

1. `test_resume_node_map_completeness` — assert all 22 keys present (W1–W11 + 11 node names)
2. `test_resume_node_map_states_valid` — assert each `pre_run_state` value is in
   `{RUN_STATE_CREATED, RUN_STATE_CLONED_INPUTS, RUN_STATE_INGESTED, ...}` constants
3. `test_artifact_validation_pass` — create tmp_path with required files; `_validate_resume_artifacts` raises nothing
4. `test_artifact_validation_fail_missing` — omit one file; assert `ValueError` message contains the missing path
5. `test_build_graph_custom_entry_point` — call `build_orchestrator_graph("draft_sections").compile()`, assert no exception
6. `test_resume_cli_unknown_worker` — use Typer `CliRunner`, call `resume --run-dir <valid_dir> --from-worker WBAD`,
   assert exit code 1 and output contains "Valid aliases"

## Failure modes

1. **Shared-library violation** — `src/launch/models/event.py` added to `allowed_paths` by mistake.
   Detection: `python tools/validate_swarm_ready.py` Gate E fails. Resolution: define
   `_EVENT_RUN_RESUMED` in `run_loop.py` instead.

2. **LangGraph rejects non-default entry point** — `graph.set_entry_point("draft_sections")`
   raises an exception if the node is not registered before the call. Detection: test 5
   (`test_build_graph_custom_entry_point`) catches this. Resolution: ensure all `add_node()`
   calls precede `set_entry_point()` in `build_orchestrator_graph()`.

3. **Backward compatibility break** — existing callers of `build_orchestrator_graph()` without
   arguments fail after signature change. Detection: full test suite (`pytest tests/ -x`).
   Resolution: default `start_node="clone_inputs"` preserves identical behaviour for all
   existing callers.

4. **run_dir already-exists guard breaks resume** — CLI `run` command currently exits 1 if
   `run_dir` exists (line ~138 of `cli/main.py`). The `resume` command must NOT inherit this
   guard. Detection: manual CLI test. Resolution: `resume` command does not call the
   already-exists check; it expects the directory to exist.

5. **events.ndjson append vs overwrite** — incorrect `open(mode="w")` would destroy the
   prior event log. Detection: integration test checking event count after resume. Resolution:
   use `append_event()` from `launch.state.event_log` which always appends.
