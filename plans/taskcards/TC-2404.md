## Objective

Parallelize Gate 17's per-file LLM calls in the W9 Validator using `ThreadPoolExecutor`.
Gate 17 (LLM Formatting Quality) iterates markdown files sequentially and makes one LLM call
per file with a 30-second timeout. For a typical 20-file run, this means up to 10 minutes
of sequential LLM calls. With 4 concurrent workers, this reduces to ~2.5 minutes.

Uses the same parallelism pattern already proven in W7 `semantic_accuracy.check_all()`.

## Implementation steps

### Step 1: Update `run_gate_17()` in `gate_17_formatting_quality.py`

Add `max_parallel_files: int = 4` parameter:
```python
def run_gate_17(
    md_files: List[Path],
    llm_client: Optional[Any],
    max_parallel_files: int = 4,
) -> Tuple[bool, List[Dict[str, Any]]]:
```

Replace the sequential `for md_path in md_files:` loop (current lines 112–119) with:
```python
# Load system prompt once — shared read-only across all file checks
system_text = _load_system_prompt()
if not system_text:
    logger.warning("[Gate17] Could not load format_fixer prompt — gate passes")
    return True, []

all_issues: List[Dict[str, Any]] = []
gate_failed = False

_n = min(len(md_files), max_parallel_files) if max_parallel_files > 1 else 1
if _n <= 1:
    for md_path in md_files:
        try:
            issues, has_errors = _check_one_page(md_path, system_text, llm_client)
            all_issues.extend(issues)
            if has_errors:
                gate_failed = True
        except Exception as exc:
            logger.warning("[Gate17] Unexpected error on %s: %s", md_path.name, exc)
else:
    from concurrent.futures import ThreadPoolExecutor, as_completed
    with ThreadPoolExecutor(max_workers=_n, thread_name_prefix="gate17_check") as pool:
        futures = {pool.submit(_check_one_page, p, system_text, llm_client): p for p in md_files}
        for fut in as_completed(futures):
            try:
                issues, has_errors = fut.result()
                all_issues.extend(issues)
                if has_errors:
                    gate_failed = True
            except Exception as exc:
                logger.warning("[Gate17] Unexpected error on %s: %s", futures[fut].name, exc)
```

Note: The current code loads `system_text` inside `_check_one_page`. Move it to `run_gate_17`
and pass it as an argument to avoid N redundant loads (one per file). Update `_check_one_page`
signature to: `_check_one_page(md_path, system_text, llm_client)` — already the case, no change.

Wait — checking the current code, `_load_system_prompt()` is already called once at `run_gate_17`
level (lines 104–107). The per-file loop calls `_check_one_page(md_path, system_text, llm_client)`.
So the only change is wrapping the per-file loop in `ThreadPoolExecutor`.

## Failure modes

1. **LLM unavailable** — Detection: `llm_client is None` check at top of `run_gate_17` returns
   early before the ThreadPoolExecutor. No change to this path.
2. **Thread exception in `_check_one_page`** — Detection: `fut.result()` raises. Resolution:
   exception caught, file skipped (same as sequential `except Exception` behavior).
3. **`gate_failed` race condition** — Detection: multiple threads may set `gate_failed = True`
   concurrently; `gate_failed |= has_errors` or separate list of booleans. Resolution: use
   a list of booleans and `any()` after all futures complete to avoid GIL-unsafe mutation
   OR rely on Python's GIL (bool assignment is atomic in CPython). Use separate list for safety.
4. **`max_parallel_files_g17` absent from run_config** — Detection: `.get(..., 4)` returns 4.
   Backward-compatible.
