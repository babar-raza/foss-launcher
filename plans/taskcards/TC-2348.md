## Objective

Update the ruleset page quotas and add new optional_page_policies to support format conversion pages in products, how-to articles in KB, and feature blog posts in blog. This enables the new page types introduced by TC-2342/TC-2343 to be generated within expanded quota limits.

## Required spec references

- `specs/rulesets/ruleset.v1.yaml` -- Section quotas and optional_page_policies definitions
- Plan: `partitioned-shimmying-adleman.md` -- Round 3 Track E configuration

- Update `products.max_pages` from 6 to 10

- Update `kb.max_pages` from 10 to 20
- Add `howto_article` optional_page_policy to kb section (preserving existing policies)
- Update `blog.max_pages` from 3 to 8

## Failure modes

1. **YAML syntax error after edit** -- Detection: YAML parse failure. Resolution: Validate with a YAML parser before committing. Spec link: ruleset.v1.yaml schema_version field.
2. **Existing optional_page_policies overwritten instead of appended** -- Detection: Diff review shows removed policies. Resolution: Always append new policies after existing entries, never replace the list. Spec link: ruleset.v1.yaml sections.kb.optional_page_policies.
3. **Quota values set too high causing performance degradation** -- Detection: Pilot runs generate excessive pages or timeout. Resolution: Use conservative increases aligned with plan (10, 15, 20, 8). Gate link: budgets.max_file_writes in run_config.
