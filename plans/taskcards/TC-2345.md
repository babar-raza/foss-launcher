## Objective

Register a dedicated `format_conversion` generator for per-format conversion pages (e.g., CSV to PDF). Extracts source_format/target_format from content_strategy.

## Required spec references

- specs/07_section_templates.md: Page role definitions

## Scope

- Create format_conversion.txt prompt
- Add generate_format_conversion_content() and fallback
- Register with aliases=["conversion", "converter"]

## Inputs

- page with content_strategy.source_format and content_strategy.target_format
- product_facts with claims
- snippet_catalog

## Outputs

- Markdown with: Overview, How It Works, Code Example, FAQ

## Allowed Paths

- `src/launch/workers/w5_section_writer/generators/content_generators.py`
- `src/launch/workers/w5_section_writer/generators/__init__.py`
- `src/launch/workers/w5_section_writer/prompts/format_conversion.txt`
- `tests/unit/workers/test_tc_440_section_writer.py`
- `plans/taskcards/TC-2345.md`

## Implementation Steps

1. Create format_conversion.txt prompt with format placeholders
2. Add generate_format_conversion_content() function
3. Add _build_deterministic_format_conversion() fallback
4. Register in __init__.py
5. Add unit tests

## Failure Modes

1. Missing format info -> default to "source"/"target"
2. No conversion claims -> use general claims
3. Prompt format error -> test with all fields
