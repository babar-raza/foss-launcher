## Objective

Add `demo_snippet_ids` field to each claim in `product_facts["claims"]` by linking
claims to the 0-2 most similar code snippets from `snippet_catalog.json` using
TF-IDF cosine similarity. This allows W5 generators to inject the correct snippet
adjacent to the claim it demonstrates, eliminating "LLM guesses which snippet
shows which feature" (RCA S-2, H5 Option B).

**Root cause (RCA H5, H3)**: Claims have no binding to the snippets that demonstrate
them. W5 generators select first-5 snippets from catalog regardless of claim topic.

## Scope

### In scope

- Add `link_claims_to_snippets(claims, snippet_catalog, max_per_claim=2)` to
  `src/launch/workers/w4_ia_planner/worker.py`:
  - Loads `embeddings.py` TF-IDF (reuse existing module from W2)
  - For each claim: compute cosine similarity of `claim_text` vs snippet `code + tags`
  - Set `demo_snippet_ids: List[str]` = top-2 snippet_ids with score > 0.0
  - If all scores are zero (no vocabulary overlap), sets `demo_snippet_ids: []`
  - Preserves existing `demo_snippet_ids` if already set (idempotent)
- Call `link_claims_to_snippets()` in the W4 `run()` function immediately after
  loading both `product_facts` and `snippet_catalog` (line ~3673)
  - Updates `product_facts["claims"]` in-place
  - Wrapped in `try/except` — linking failure MUST NOT crash W4
- Add 4 unit tests in `tests/unit/workers/test_tc_430_ia_planner.py`

### Out of scope

- Changing the claim_id computation (SHA256 unchanged)
- Modifying snippet_catalog schema
- Changing W2 extract_claims.py
- Implementing per-role context builders (that is TC-2369)

## Integration Point

W4 is the first worker that has access to BOTH `product_facts.json` (from W2) and
`snippet_catalog.json` (from W3). Snippet linking runs at W4 load-time before page
planning, ensuring `demo_snippet_ids` is available throughout planning and in W5.

## Implementation steps

1. Add helper `link_claims_to_snippets()`:
   ```python
   def link_claims_to_snippets(
       claims: List[Dict[str, Any]],
       snippet_catalog: Dict[str, Any],
       max_per_claim: int = 2,
   ) -> List[Dict[str, Any]]:
       """Link each claim to 0-2 most similar code snippets via TF-IDF.

       TC-2368: Claim-to-snippet binding (RCA S-2, H5 Option B).
       """
       snippets = snippet_catalog.get("snippets", [])
       if not snippets or not claims:
           return claims
       try:
           from ..w2_facts_builder.embeddings import (
               tokenize, compute_idf, compute_tfidf_vector, cosine_similarity,
           )
       except ImportError:
           return claims
       # Tokenize snippets: code content + tags
       snippet_tokens = [
           tokenize(s.get("code", "") + " " + " ".join(s.get("tags", [])))
           for s in snippets
       ]
       # Tokenize claims
       claim_tokens_list = [tokenize(c.get("claim_text", "")) for c in claims]
       # Build IDF over claim texts + snippet texts
       all_docs = claim_tokens_list + snippet_tokens
       idf = compute_idf(all_docs)
       # Pre-compute snippet TF-IDF vectors
       snippet_vecs = [compute_tfidf_vector(toks, idf) for toks in snippet_tokens]
       updated = []
       for claim, ctoks in zip(claims, claim_tokens_list):
           c = dict(claim)
           if c.get("demo_snippet_ids") is not None:
               updated.append(c)
               continue
           cvec = compute_tfidf_vector(ctoks, idf)
           scored = sorted(
               [(cosine_similarity(cvec, svec), s.get("snippet_id", ""))
                for svec, s in zip(snippet_vecs, snippets)
                if cosine_similarity(cvec, svec) > 0.0],
               reverse=True,
           )
           c["demo_snippet_ids"] = [sid for _, sid in scored[:max_per_claim] if sid]
           updated.append(c)
       return updated
   ```

2. In the W4 `run()` function, after loading both artifacts (~line 3672):
   ```python
   # TC-2368: Link claims to demo snippets
   try:
       product_facts["claims"] = link_claims_to_snippets(
           product_facts.get("claims", []),
           snippet_catalog,
       )
   except Exception as _link_err:
       logger.warning("claim_snippet_linking_failed", error=str(_link_err))
   ```

3. Add 4 unit tests:
   - `test_link_claims_basic_match`: claim text overlapping snippet code gets demo_snippet_id
   - `test_link_claims_empty_catalog`: empty snippet_catalog returns claims unchanged
   - `test_link_claims_no_overlap`: claim with no token overlap gets empty demo_snippet_ids
   - `test_link_claims_preserves_existing`: claims already with demo_snippet_ids unchanged
