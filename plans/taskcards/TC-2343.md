## Objective

Add three new optional page source handlers to `generate_optional_pages()` in W4 IAPlanner: per_format_conversion, per_howto_cluster, and per_feature_blog. These sources enable the pipeline to generate format conversion pages (products), how-to articles (KB), and per-feature blog posts, matching aspose.net content patterns.

## Failure modes

1. **Missing claim_groups keys** - Detection: handler uses .get() with defaults (empty list/dict). Resolution: already defensive. Spec: specs/06_page_planning.md.
2. **Empty candidates from valid data** - Detection: test asserts len(pages) > 0 for valid input. Resolution: verify threshold logic (per_howto_cluster requires >= 3 claims, per_feature_blog requires matching snippets). Gate: test assertions.
3. **Slug collision with existing sources** - Detection: generate_optional_pages sorts by (priority, quality_score, slug) deterministically. Resolution: new source slugs use distinctive prefixes (e.g., "how-to-", "{src}-to-{tgt}"). Gate: check_url_collisions.
